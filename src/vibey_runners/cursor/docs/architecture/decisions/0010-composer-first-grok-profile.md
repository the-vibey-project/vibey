# Composer-first; Grok is a model profile

- Status: Accepted
- Date: 2026-08-13

## Context
Pressure to treat Grok as a second product would dilute the capacity taxonomy.

## Decision
Default model profile is `composer-2.5`. Grok is one ModelProfile among presets — never a separate adapter or CLI product.

## Consequences
Any change requires an ADR explaining why a profile is insufficient.
