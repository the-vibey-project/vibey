# Roadmap

**Goal:** a production-grade autonomous session runner over Cursor's agent and Cloud Agents API — bounded, never-blocking, auditable — as the Cursor member of the five-runner family.

This roadmap is **living** (vibey-gh#211): it stays active until the goal above is
achieved and every active contributor has clearly agreed the project is done —
neither is ever assumed. Changes requested while this file is stale are treated as
a risk requiring human confirmation.

## Now

- Doctrine wave: paper published on the site; docs suite rebuilt to the arc.
- Cloud Agents surface (`cloud` group) tracked against the vendor API.

## Next

- Live-testing cadence (`pytest -m live`) against real accounts each release.
- Capacity lexicon updates as Cursor's messaging evolves.

## Done means

The runner needs no code changes across a full quarter of vendor changes — only config/lexicon edits — and contributors sign off that the transplant is complete.
