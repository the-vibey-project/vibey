# Getting help with claudeloop

Please do **not** open a bug issue for a usage question. Use the channel
that matches what you need:

| I want to... | Go here |
|---|---|
| Install, configure, or run an unattended session | [Documentation](https://github.com/the-vibey-project/vibey/blob/develop/src/vibey_runners/claude/docs/index.md) |
| Ask a question or discuss design | [GitHub Discussions](https://github.com/the-vibey-project/vibey/discussions) |
| Report a bug | [Bug report](https://github.com/the-vibey-project/vibey/issues/new?template=bug_report.yml) |
| Propose a feature | [Feature request](https://github.com/the-vibey-project/vibey/issues/new?template=feature_request.yml) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) — privately, never as a public issue |
| Contribute code | [CONTRIBUTING.md](CONTRIBUTING.md) |

This project is **macOS and Linux only**. Windows is not a supported target;
see [installation](docs/getting-started/installation.md).

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
