# Roadmap

**Goal:** the Gemini/Antigravity member of the runner family — quota-aware autonomy over both vendor planes (Developer, Vertex), drift-gated generated surfaces, proven auth.

This roadmap is **living** (vibey-gh#211): it stays active until the goal above is
achieved and every active contributor has clearly agreed the project is done —
neither is ever assumed. Changes requested while this file is stale are treated as
a risk requiring human confirmation.

## Now

- Doctrine wave: paper published; docs at the arc.
- Milestone M5 shipped: pure domain core, autonomous runner, adaptive waiting, agy CLI, savepoints, ops CLI, drift-gated REST.

## Next

- Post-M5: broaden the generated Vertex surface as the vendor stabilizes it.
- Quota-model updates as Google's reset behavior evolves.

## Done means

A quarter of vendor churn absorbed by lexicon/config alone, and contributors sign off the transplant is complete.
