# Claude Code skills

This file exists to satisfy `vibey-gh`'s documentation contract, which expects a skills
index at this path. This repository's actual product — 710 Agent Skills across 135
Claude Code plugins — lives under
[plugins/](https://github.com/the-vibey-project/vibey-skills/tree/main/plugins), one
`SKILL.md` per skill directory, indexed by
[.claude-plugin/marketplace.json](https://github.com/the-vibey-project/vibey-skills/blob/main/.claude-plugin/marketplace.json).
Install this marketplace in Claude Code with `/plugin marketplace add
adammatthewsteinberger/vibey-skills`, then `/plugin install <plugin-name>`.

See the generated
[skills reference](https://the-vibey-project.github.io/vibey-skills/reference/) for a
browsable index, or
[CLAUDE.md](https://github.com/the-vibey-project/vibey-skills/blob/main/CLAUDE.md) for
how a plugin and a skill are structured.
