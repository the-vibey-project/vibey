# Project rules

rules file at this path. The actual conventions for this repository live in one place:

[CLAUDE.md](https://github.com/the-vibey-project/vibey-skills/blob/main/CLAUDE.md) —
what this repository is, how plugins and skills are structured, and the branching,
versioning, and release rules that govern a change. Any AI agent working in this
repository should read that file first.
