# Frontend Design Plugin

Skills for frontend design, UX/UI, Next.js patterns, and performance optimization.

- **graphic-ux-ui-design**: Evidence-based graphic design, UX/UI, accessibility (WCAG 2.x), design systems, and component patterns.
- **nextjs-patterns**: Next.js App Router production patterns, security, rendering, caching, and auth (v14/v15/v16).
- **performance-optimization**: Performance optimization for Python, Next.js/TypeScript, and Azure cloud workloads.
