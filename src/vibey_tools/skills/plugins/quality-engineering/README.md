# Quality Engineering

Skills for Python testing on Azure, enterprise test strategy, and production debugging and observability.

## Skills

- **python-quality-testing** — Python testing with pytest, coverage, mutation testing, and Azure Pipelines integration
- **test-strategy** — Test strategy design: pyramid, risk-based testing, quality gates, and shift-left practices
- **debugging-and-observability** — Debugging, structured logging, error handling, and observability: OpenTelemetry, the four signals, eBPF, SLO burn-rate alerting, and resilience patterns
