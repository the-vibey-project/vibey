# Christian Courtship Skills Plugin

**Author:** Adam Matthew Steinberger  
**Version:** 0.1.0  
**Category:** Philosophy / Theology / Relational Ethics  

## Overview

The `christian-courtship` plugin provides an operational, evidence-grounded framework for navigating relational progression from community friendship to solemn engagement and indissoluble covenant marriage. It synthesizes classical Christian dogma across Protestant, Catholic, and Greek Orthodox traditions with modern commitment theory, family systems differentiation, and formal game-theoretic verification.
