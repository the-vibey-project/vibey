# DIY Kit Dev Plugin

Hobbyist and maker hardware development for software engineers who want to build hardware: choosing the right board, the current Raspberry Pi, Arduino and ESP32 lineups and what changed, the electronics fundamentals that stop you destroying things, power (the single biggest cause of mystery failures), sensors and actuators, the software layer, physical build and soldering, hardware debugging, networking and home automation, enclosures and fabrication, and the honest path from a working prototype to something you can ship.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **maker-boards-and-platforms** — Choosing a Board, Raspberry Pi, Arduino, and the Microcontroller Field (§0–§3): Routing; Choosing a Board; Raspberry Pi; Arduino, ESP32, and the Microcontroller Field.
- **maker-power-electronics-and-io** — Power, Electronics, Sensors, and Actuators (§4–§7): Power — Read This Section; The Electronics You Actually Need; Sensors and Inputs; Outputs, Motors and Actuators.
- **maker-software-build-and-debug** — The Software Layer, Building It Physically, and Debugging Hardware (§8–§10): The Software Layer; Building It Physically; Debugging Hardware.
- **maker-networking-enclosures-and-productization** — Networking, Enclosures, Prototype to Product, and Sourcing (§11–§14): Networking and Home Automation; Enclosures and Fabrication; Prototype → Product; Buying and Sourcing.
- **maker-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
