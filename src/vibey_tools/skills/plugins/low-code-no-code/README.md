# Low-Code / No-Code Plugin

Low-code and no-code platforms across the whole spectrum — block-based education tools, workflow automation, integration and iPaaS, data pipelines and ETL, app builders, RPA, and the AI app-generation wave now reshaping the category. Written for engineers and technical leaders who have to evaluate, govern, integrate with, or replace these tools: what they genuinely do well, the governance and escape-hatch problems that bite later, licensing traps, the security evidence, and the honest question of when to write code instead.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **lowcode-integration-data-and-app-builders** — Integration and iPaaS, Data Pipelines, App Builders, and RPA (§5–§8): Integration and iPaaS; Data Pipelines and ETL; App Builders; RPA.
- **lowcode-adoption-governance-and-security** — When to Use It, Governance, Licensing, and Security (§9–§12): When to Use — and When Not To; Governance and Shadow IT; Licensing and Cost Traps; Security.
- **lowcode-lock-in-and-engineering-practice** — Escape Hatches and Lock-In, and Engineering Practice (§13–§14): Escape Hatches and Lock-In; Engineering Practice Inside Low-Code.
- **lowcode-reference** — Anti-Patterns, Contested Questions, Currency, and Resources (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; Resources; Quick Reference; Sources and Method.
