# Algorithms Deep Dive Plugin

A practical reference for algorithms and data structures aimed at working software engineers: how to choose and reason about them, the machine model that makes asymptotic analysis lie, the core structure families and their real trade-offs, sorting and searching as libraries actually implement them, graphs, strings and dynamic programming, probabilistic and streaming structures, vector and similarity search, concurrent structures, and the measurement discipline that separates real optimization from folklore.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **algo-foundations-and-machine-model** — Choosing, and the Machine You Are Actually Programming (§0–§2): Routing; Choosing; The Machine You Are Actually Programming.
- **algo-data-structures** — Arrays, Hash Tables, Trees, and Heaps (§3–§6): Arrays and Sequences; Hash Tables; Trees and Ordered Structures; Heaps and Priority Queues.
- **algo-core-algorithms** — Sorting, Searching, Graphs, Strings, and Dynamic Programming (§7–§11): Sorting; Searching and Indexing; Graphs; Strings and Text; Dynamic Programming, Greedy, and Amortization.
- **algo-probabilistic-concurrency-and-measurement** — Probabilistic Structures, Measurement, and Concurrency (§12–§14): Probabilistic and Streaming Structures; Measurement; Concurrent Data Structures.
- **algo-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
