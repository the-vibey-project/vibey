# Developer Experience Plugin

The developer-experience (DevEx / DX) blueprint as working knowledge: what makes a codebase, command line, API, documentation set, interface and AI-agent surface pleasant and predictable to use, with every rule carrying an evidence grade (A = peer-reviewed or large study, B = credible practitioner or single study, C = vendor or opinion) and the thin or contested evidence flagged rather than smoothed over.

One blueprint in two parts (Part 1: the developer's experience; Part 2: device-specific interfaces and non-developer paths), split into 9 skills along its section groups so a task loads only the part it needs. Reference, not tutorial: every claim is graded, the weak-evidence section says which claims to hold loosely, and the blueprint is dated Oct 23, 2026 (the evidence base and AI-tooling claims age fastest).

## Skills

- **devex-principles-and-feedback-loops** — Principles, Evidence, and Feedback Loops: the ten graded rules, how far each source can be trusted, short feedback loops, one-command setup, a doctor command.
- **devex-cli-and-errors** — Command-Line Interfaces and Error Messages: the CLI rule table and the eight-part error-message shape.
- **devex-api-sdk-and-docs** — API and SDK Design, and Documentation: method placement, defaults, time-to-first-call, versioning; Diataxis, README first screen, executable docs.
- **devex-interfaces-onboarding-and-agents** — Interfaces, Onboarding, and AI-Agent Ergonomics: keyboard-first and accessible tools, newcomer barriers, AGENTS.md, llms.txt, MCP budgets.
- **devex-surface-placement** — Device-Specific Interfaces and the Feature-to-Surface Matrix (Part 2): the eight placement rules and where each capability lives first.
- **devex-editor-and-desktop-surfaces** — VS Code Extensions and Desktop Apps: native surfaces first, webview and notification rules, activation and disposables, the native-feel checklist.
- **devex-mobile-and-web-surfaces** — iOS, Android, and Web/PWA: what a phone is for in a developer product, widget quality tiers, installable PWAs, identity versus interaction.
- **devex-non-developers-and-visual-design** — Non-Developer Paths and Visual Design: the template-run-change-reveal-export ladder, private by default, tokens, WCAG 2.2 AA, the European Accessibility Act.
- **devex-reference** — Measurement, Launch Checklist, Weak Evidence, and Sources: the perception-plus-workflow table, the checklist, every contested claim (including Part 2's unverified ones), the sources.
