# Developer Experience Plugin

The developer-experience (DevEx / DX) blueprint as working knowledge: what makes a codebase, command line, API, documentation set, interface and AI-agent surface pleasant and predictable to use, with every rule carrying an evidence grade (A = peer-reviewed or large study, B = credible practitioner or single study, C = vendor or opinion) and the thin or contested evidence flagged rather than smoothed over.

One blueprint, split into 5 skills along its section groups so a task loads only the part it needs. Reference, not tutorial: every claim is graded, the weak-evidence section says which claims to hold loosely, and the blueprint is dated Oct 23, 2026 (the evidence base and AI-tooling claims age fastest).

## Skills

- **devex-principles-and-feedback-loops** — Principles, Evidence, and Feedback Loops (Principles; Evidence base; Codebase and feedback loops): the ten graded rules, how far each source can be trusted, short feedback loops, one-command setup, a doctor command, flaky-test quarantine.
- **devex-cli-and-errors** — Command-Line Interfaces and Error Messages (CLI; Error messages): the CLI rule table (streams, exit codes, help, color, --json, prompts, --dry-run, config precedence, telemetry) and the eight-part error-message shape.
- **devex-api-sdk-and-docs** — API and SDK Design, and Documentation (API and SDK design; Documentation): method placement, defaults, time-to-first-call, idempotency, versioning and deprecation; the Diataxis split, README first screen, executable docs.
- **devex-interfaces-onboarding-and-agents** — Interfaces, Onboarding, and AI-Agent Ergonomics (Interfaces: web UI, TUI, accessibility; Onboarding and open-source contribution; AI-agent ergonomics): keyboard-first and accessible tools, newcomer barriers and golden paths, AGENTS.md, llms.txt, MCP tool budgets.
- **devex-reference** — Measurement, Launch Checklist, Weak Evidence, and Sources (Measurement and launch checklist; Where the evidence is weak or conflicting; Sources): the perception-plus-workflow table, the launch checklist, every contested claim, and the primary sources.
