# Linux Server Administration Plugin

Linux server administration as a working discipline: the filesystem and the file semantics that surprise people, users, permissions and capabilities, processes and resource control, systemd from the unit model through hardening directives and timers, storage and filesystems, networking and a diagnosis order that works, packages and distributions, boot, security hardening, observability and performance including eBPF, a troubleshooting methodology, containers and namespaces, configuration management, and backup and recovery.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **sysadmin-filesystem-permissions-and-processes** — The Filesystem, Users and Permissions, and Processes (§0–§3): Routing; Filesystem and Files; Users, Permissions, Capabilities; Processes and Resources.
- **sysadmin-systemd-storage-and-networking** — systemd, Storage, and Networking (§4–§6): systemd; Storage; Networking.
- **sysadmin-packages-boot-and-hardening** — Packages and Distributions, Boot, and Security Hardening (§7–§9): Packages and Distributions; Boot; Security Hardening.
- **sysadmin-observability-troubleshooting-and-operations** — Observability, Troubleshooting, Containers, Automation, and Backup (§10–§14): Observability and Performance; Troubleshooting Methodology; Containers and Namespaces; Automation and Configuration Management; Backup and Recovery.
- **sysadmin-reference** — Anti-Patterns, Limits, Lifecycle Dates, and Command Reference (§15–§20): Anti-Patterns; Numbers and Limits; Lifecycle Dates; Books; Command Reference; Method.
