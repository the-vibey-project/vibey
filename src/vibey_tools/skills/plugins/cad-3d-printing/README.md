# CAD and 3D Printing Plugin

CAD and additive manufacturing for engineers who script and automate: geometry representations and kernels, file formats and what each one loses, code-CAD and parametric modelling, mesh processing and repair, the slicing pipeline and G-code, the printing processes and the physics that actually determines part quality, design for additive manufacturing, tolerances and fits, materials, generative design and lattices, automation pipelines, and scanning and reverse engineering.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **cad-geometry-kernels-formats-and-code-cad** — Geometry Representations, Kernels, File Formats, and Code-CAD (§0–§4): Routing; Geometry Representations; Kernels; File Formats — and what each one loses; Code-CAD and Scripting.
- **cad-slicing-pipeline-and-processes** — The Slicing Pipeline and the Printing Processes (§5–§6): The Slicing Pipeline; The Processes.
- **cad-design-tolerances-and-materials** — Design for Additive Manufacturing, Tolerances and Fits, and Materials (§7–§9): Design for Additive Manufacturing; Tolerances and Fits; Materials.
- **cad-generative-automation-and-scanning** — Generative Design, Automation Pipelines, and Scanning (§10–§12): Generative Design and Lattices; Automation Pipelines; Scanning and Reverse Engineering.
- **cad-reference** — Anti-Patterns, Numbers, What Moved, and Tools (§13–§18): Anti-Patterns; Numbers; Books and Tools; What Actually Moved; Quick Reference; Method.
