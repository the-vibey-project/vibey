Skills for secure pipeline design, CI/CD platform strategy, and GitHub/Atlassian practice.

- **bitbucket-azure** — Bitbucket Pipelines for Azure DevOps shops: branching strategies, environments, and security gates
- **cicd-field-guide** — 2025–2026 CI/CD field guide: DORA metrics, platform selection, trunk-based development, OIDC, supply-chain security (SLSA/Sigstore/SBOMs), GitOps, and progressive delivery
- **github-atlassian** — Advanced GitHub and Atlassian (Jira, Confluence, JSM, Bitbucket) reference: rulesets, merge queue, GHAS, Copilot, Rovo, Forge, and the GitHub↔Jira integration pattern
