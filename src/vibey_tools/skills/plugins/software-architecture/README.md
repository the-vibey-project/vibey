# Software Architecture Plugin

Skills for production software architecture and Azure architecture patterns.

- **software-architecture**: Modular monolith to microservices, API design, Python/Next.js/Azure stack decisions, observability, ADRs.
- **architecture-patterns**: Azure compute, messaging, data, and AI architecture patterns with WAF guidance and resilience catalog.
- **software-design**: The software design process — just-enough design, SOLID/DRY/KISS/YAGNI as heuristics, ADRs, C4 model, fitness functions, DDD, and evolutionary architecture.
