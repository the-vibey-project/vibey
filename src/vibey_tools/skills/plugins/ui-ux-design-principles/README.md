# UI/UX Design Principles — Mobile, Tablet, Web, Desktop Plugin

A deep technical reference for UI/UX design across mobile, tablet, web, and desktop: the perceptual and cognitive science that explains why interfaces work or don't, usability heuristics and where they fail, information architecture and navigation, interaction and input models per form factor, layout and adaptation, visual design and design-system operations, platform conventions, accessibility law and practice, content and UX writing, forms and conversion, research and evaluation methods, ethics and dark-pattern regulation, and AI-era interface patterns. It complements the implementation-oriented `graphic-ux-ui-design` skill in the `frontend-design` plugin.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **ui-ux-cognition-heuristics-and-navigation** — The Science Underneath, Usability Heuristics, and Information Architecture (§0–§3): Routing; The Science Underneath — why interfaces work or don't; Usability Heuristics and Mental Models; Information Architecture and Navigation.
- **ui-ux-interaction-layout-and-visual-design** — Input and Interaction, Layout and Responsiveness, and Visual Design (§4–§6): Input and Interaction; Layout, Responsiveness, and Adaptation; Visual Design.
- **ui-ux-design-systems-platforms-and-accessibility** — Design Systems and Tokens, Platform Conventions, and Accessibility (§7–§9): Design Systems and Tokens; Platform Conventions; Accessibility.
- **ui-ux-writing-forms-research-and-ethics** — UX Writing, Forms and Conversion, Research, Ethics, and AI-Era Interfaces (§10–§14): Content and UX Writing; Forms, Onboarding, and Conversion; Research and Evaluation; Ethics, Persuasion, and Dark Patterns; AI-Era Interfaces.
- **ui-ux-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
