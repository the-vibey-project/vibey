# Loving People Well Skills Plugin

**Author:** Adam Matthew Steinberger  
**Version:** 0.1.0  
**Category:** Philosophy / Theology / Relational Ethics  

## Overview

The `loving-people-well` plugin provides an operational, backward-induction framework for loving human beings within everyday life. It operationalizes Richard Bellman's principle of backward induction across five distinct structural tiers: descending from terminal surrender and open-handed release down through bounded mercy, cognitive memory systems, unhurried time cadence, and distraction-free focused attention.
