# Entertainment, Comedy, Drama and Storytelling Plugin

Storytelling and performance craft in a domain with an unusually loud rules industry — the techniques are real and teachable, the “rules” sold alongside them are mostly heuristics presented as laws. What a story is, character and desire, structure models assessed honestly, scene construction, conflict and tension, dialogue, point of view, theme, exposition and endings; comedy theory and joke mechanics, improv, standup, timing and an honest treatment of offence; acting and directing systems; how medium shapes form; and the industry's development process and economics.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
