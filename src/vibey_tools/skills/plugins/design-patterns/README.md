# Design Patterns Plugin

Design patterns as working knowledge: what a pattern actually is, the honest critique of the Gang of Four and which of the 23 survive in modern languages, the functional and data-oriented alternatives, architectural patterns from layered through hexagonal and DDD to microservices, distributed and resilience patterns, concurrency and messaging patterns, the emerging LLM and agentic pattern language, and — most importantly — the anti-patterns of over-application, which are the dominant failure mode in this domain.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **patterns-foundations-gof-and-alternatives** — What a Pattern Is, the GoF Audit, and the Alternatives (§0–§5): Routing; What a Pattern Is; The Honest Critique of GoF; The GoF Audit; Functional and Data-Oriented Alternatives; Dependency Injection and Inversion.
- **patterns-architectural** — Architectural Patterns, Monoliths, Modules, and Microservices (§6–§7): Architectural Patterns; Monoliths, Modules, and Microservices.
- **patterns-distributed-concurrency-and-messaging** — Distributed Data, Resilience, Concurrency, and Messaging (§8–§11): Distributed Data Patterns; Resilience Patterns; Concurrency Patterns; Integration and Messaging.
- **patterns-llm-agentic-and-legacy-migration** — LLM and Agentic Patterns, and Migration and Legacy Patterns (§12–§13): LLM and Agentic Patterns; Migration and Legacy Patterns.
- **patterns-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§14–§20): Anti-Patterns; Anti-Patterns Table; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
