# Math and Science Programming Plugin

Numerical and scientific computing for engineers doing numerical work, and for scientists who ended up writing production software by accident: floating-point arithmetic and the errors it causes, conditioning and stability, the BLAS/LAPACK substrate, the tool landscape and how to choose, symbolic versus numeric computation, linear systems, ODEs and PDEs, optimization, statistics and uncertainty, high-performance and GPU computing, and the verification, validation and reproducibility practices that separate trustworthy scientific software from plausible-looking output.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **sci-floating-point-and-numerical-foundations** — Floating Point, Conditioning and Stability, and the BLAS/LAPACK Substrate (§0–§3): Routing; Floating Point; Conditioning and Stability; The Substrate: BLAS and LAPACK.
- **sci-tooling-and-symbolic-computation** — Choosing a Tool, and Symbolic Computation (§4–§5): Choosing a Tool; Symbolic Computation.
- **sci-linear-algebra-differential-equations-and-optimization** — Linear Algebra, Differential Equations, Optimization, and Quadrature (§6–§9): Linear Algebra; Differential Equations and Simulation; Optimization; Interpolation, Quadrature, Transforms.
- **sci-statistics-performance-and-reproducibility** — Statistics, Performance, Testing, and Reproducibility (§10–§14): Statistics and Uncertainty; Performance and Parallelism; Data, I/O, and Units; Testing and Verification; Reproducibility.
- **sci-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
