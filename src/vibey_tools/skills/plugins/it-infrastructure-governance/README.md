# IT Infrastructure and Governance Plugin

Enterprise IT infrastructure and the governance layer over it: the infrastructure layers, compute and virtualization, storage and networking, directory services and hybrid identity, authentication and authorization, privileged access, the identity lifecycle and access certification, segregation of duties, endpoint management and patching, backup, DR and continuity, monitoring and logging, ITSM and change management, asset and configuration management, the governance frameworks, capacity and lifecycle, and vendor and third-party risk.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
