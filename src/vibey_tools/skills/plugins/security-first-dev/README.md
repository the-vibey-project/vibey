# Security-First Development

Skills for building secure software from greenfield through legacy modernization.

## Skills

- **security-first-scrum** — Security-First Scrum methodology with Three Laws, Onion architecture, TDD RED→GREEN→REFACTOR→SCAN→COMMIT, and .NET 8/Azure/React/Cosmos stack
- **codebase-modernization** — Legacy codebase migration using P0-P3 triage, 8 migration phases, and Strangler Fig pattern
- **cybersecurity-implementation** — 6-domain enterprise security implementation covering identity, network, endpoint, application, data, and SOC/IR
