# Security Principles

Skills for foundational security, threat modeling, AI-era cybersecurity, secure AI development, and confidential AI inference.

## Skills

- **cybersecurity-principles** — Saltzer-Schroeder principles, CIA triad, Zero Trust, and defense-in-depth
- **threat-modeling-playbook** — STRIDE, PASTA, LINDDUN threat modeling methodologies and MITRE ATT&CK mapping
- **ai-era-security** — June 2026 field guide: OWASP LLM Top 10, Agentic Top 10, post-quantum cryptography (FIPS 203/204/205), EU AI Act, and Microsoft Entra Agent ID
- **ai-security-practices** — Securing AI systems in Python and TypeScript/Next.js: prompt injection defense, OWASP LLM/ASI Top 10, MCP and RAG security, guardrails, and NIST AI RMF
- **confidential-ai-inference** — October 2026 reference: protecting prompts, outputs and weights from the cloud operator, verifiably — TEEs (AMD SEV-SNP, Intel TDX, Arm CCA, NVIDIA GPU confidential computing), RATS remote attestation (RFC 9334), attested TLS, Oblivious HTTP (RFC 9458), transparency logs, zkML, a reference architecture and a deployment checklist
