# DNS, Domain Names and Naming Systems Plugin

The internet's naming layer, in three parts: the protocol, the governance, and the alternatives. DNS resolution, record types, zones, delegation, glue and caching, then the security history from cache poisoning through DNSSEC to encrypted transport, plus operations and DNS as critical infrastructure; the governance and commercial structure of domain names — ICANN and the root, TLD types, the registry, registrar and registrant model, registration mechanics, WHOIS and RDAP, disputes, domain security and the aftermarket; and the blockchain naming alternatives, ENS and Handshake among them, assessed against what they actually deliver.

One reference, split into 6 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (checked August 2026) flags what goes stale first.
