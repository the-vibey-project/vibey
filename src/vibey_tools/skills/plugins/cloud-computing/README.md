# Cloud Computing Plugin

Cloud fundamentals and production practice for software engineers: the service and deployment models and what they actually cost, the provider landscape and how to choose, the core primitives, architecture and the Well-Architected trade-offs, resilience and the hard lessons of the 2025 outages, cost engineering and FinOps, security and shared responsibility, sovereignty under the EU Data Act, operations and observability, migration, multi-cloud and lock-in, sustainability, and AI-workload economics.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **cloud-cost-security-and-operations** — Cost Engineering, Security, and Operations (§7–§9): Cost Engineering and FinOps; Security and Shared Responsibility; Operations and Observability.
- **cloud-migration-sovereignty-and-ai-workloads** — Migration, Sovereignty, Multi-Cloud, AI Workloads, and Sustainability (§10–§14): Migration; Sovereignty, the EU Data Act, and Egress; Multi-Cloud and Lock-In; AI Workloads; Sustainability.
- **cloud-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
