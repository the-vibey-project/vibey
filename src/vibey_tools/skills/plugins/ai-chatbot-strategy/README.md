# AI Chatbot Strategy Plugin

Business-oriented guide to AI chatbots — from fundamentals through deployment and ROI.

- **ai-chatbot-fundamentals**: AI types, ML/deep learning, NLP, chatbot architecture, training data, business value cases.
- **rag-architecture-business**: RAG explained for business — the static AI problem, vector databases, embeddings, and when RAG is the right choice.
- **chatbot-build-and-deploy**: Custom chatbot build process — purpose definition, four functional layers, guardrails, data privacy, hallucination mitigation, five-phase deployment.
- **chatbot-business-value**: ROI frameworks, industry case studies, organizational readiness, cost spectrum, and when (and when not) to build.
