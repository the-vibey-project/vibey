# Smart TV App Development Plugin

A deep technical reference for building applications on connected-TV platforms: the platform landscape and each platform's programming model, the 10-foot UI and focus-driven navigation, remote-control input, video playback and adaptive streaming, DRM, performance and memory discipline on constrained hardware, lifecycle and deep linking, monetization and CTV advertising, certification and store submission, cross-platform strategy, testing on real devices, analytics and quality of experience, and accessibility, privacy, and regulation.

One reference, split into 4 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **smart-tv-platforms-and-10-foot-ui** — The Platform Landscape, the 10-Foot UI, and Focus and Input (§0–§3): Routing; The Platform Landscape; The 10-Foot UI; Focus and Input.
- **smart-tv-playback-drm-and-performance** — Video Playback, DRM, Performance and Memory, and Lifecycle (§4–§7): Video Playback; DRM; Performance and Memory; Lifecycle, Deep Linking, and Discovery.
- **smart-tv-monetization-certification-and-operations** — Monetization, CTV Advertising, Certification, Testing, Analytics, and Cross-Platform (§8–§14): Monetization; CTV Advertising; Certification and Submission; Testing; Analytics and QoE; Cross-Platform Strategy; Accessibility, Privacy, and Regulation.
- **smart-tv-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§15–§20): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
