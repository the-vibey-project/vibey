# Reporting and Dashboards Plugin

Building reporting and dashboards that give correct answers: the architecture, dimensional modelling, the aggregation traps that silently produce wrong numbers, metric definition pitfalls, the semantic layer, time handling, query performance, caching and freshness, dashboard design and chart selection, alerting, access control, embedded analytics, and how to test analytics — plus an evidence-based read on the semantic layer market and natural-language querying.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **reporting-dashboard-design-charts-and-alerting** — Dashboard Design, Chart Selection, and Alerting (§9–§11): Dashboard Design; Chart Selection; Alerting.
- **reporting-access-control-embedded-and-testing** — Access Control, Embedded Analytics, and Testing Analytics (§12–§14): Access Control; Embedded Analytics; Testing Analytics.
- **reporting-reference** — Misconceptions, What Moved, Numbers, and Canon (§15–§20): Misconceptions; What Moved; Numbers; Books; Quick Reference; Method.
