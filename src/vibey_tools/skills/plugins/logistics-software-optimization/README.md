# Logistics and Optimization Software Plugin

Building optimization software for logistics, written around why these projects fail as often as they do: complexity assessed honestly, linear programming, MIP and branch-and-bound, how to model well, constraint programming, metaheuristics, local search and LNS, bounds and solution quality; shortest path and network flow, the TSP, vehicle routing as the core problem, packing, assignment, scheduling and facility location; inventory, forecasting, warehouse operations and last mile; the data layer that decides most outcomes; dynamic and stochastic variants; and the solver and tooling landscape.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **logistics-constraint-programming-metaheuristics-and-bounds** — Constraint Programming, Metaheuristics, Local Search, and Bounds (§6–§9): Constraint Programming; Metaheuristics; ⚠️ Local Search and Large Neighbourhood Search; Bounds and Solution Quality.
- **logistics-routing-packing-scheduling-and-network-design** — Shortest Path, TSP, Vehicle Routing, Packing, Assignment, Scheduling, and Facility Location (§10–§16): Shortest Path and Network Flow; TSP; ⚠️ Vehicle Routing — The Core Problem; Packing and Loading; Assignment and Matching; Scheduling; Facility Location and Network Design.
- **logistics-inventory-forecasting-operations-and-solvers** — Inventory, Forecasting, Warehouse and Last-Mile Operations, Data, Stochastic Problems, and Solvers (§17–§24): Inventory; Forecasting; The Landscape; Warehouse Operations; Last Mile; ⚠️ Data; Dynamic and Stochastic; Solvers and Tooling.
- **logistics-reference** — What's Live, Anti-Patterns, Misconceptions, and Canon (§25–§31): What's Live; ⚠️ Anti-Patterns; Misconceptions; Numbers; Books; Quick Reference; Method.
