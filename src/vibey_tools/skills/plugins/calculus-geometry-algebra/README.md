# Calculus, Geometry and Algebra Plugin

The mathematics an engineer actually reaches for, developed so the structure is visible rather than the formulas alone: linear algebra from vector spaces through the four fundamental subspaces, eigenvalues, the spectral theorem and SVD, factorizations and conditioning; calculus from the derivative and integration through series, multivariable and vector calculus; differential forms, constrained optimization and differential equations; and geometry from manifolds and tensors through Riemannian geometry and Lie groups.

One reference, split into 6 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
