# Patents, Trademarks and Copyrights Plugin

How to file and maintain US patents, trademarks and copyrights for a software product, brand or invention in October 2026: which right protects what, what to file first (the name and the code, with the patent as a deliberate decision), clearance and trademark prosecution, the copyright Registration Portal and software deposits, patent documentation, search, provisional and utility filing, ownership and assignments, open source and AI-assisted code, trade secrets, enforcement costs, budgets, deadlines, scams and free help. General information, not legal advice.

One reference, split into 7 skills along its Parts so a task loads only the part it needs. Part numbers and section numbers (§1.1–§6.4) are shared across the set and cross-references into a sibling skill are written as text, not links.
