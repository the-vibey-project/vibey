# Chaos Theory Plugin

Chaos and nonlinear dynamics stated precisely, with attention to what the theory does and does not license: what chaos is and is not, the stretch-and-fold mechanism, dynamical systems and stability, bifurcations, the logistic map and Feigenbaum universality, Lyapunov exponents, strange attractors, the routes to chaos, fractals and dimension, Poincare sections, Hamiltonian chaos and KAM, detecting chaos in real data, control and synchronization, where it genuinely appears, and the numerics.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
