# Flight Software Plugin

Spacecraft flight software as an engineering discipline: what actually makes it different, architecture and the frameworks worth knowing, languages and coding standards including Rust's real status, flight processors, radiation effects in software terms, real-time discipline and RTOS choice, FDIR, time and clocks, command and telemetry, data handling and in-flight update, GNC software, verification and validation, the ground segment, onboard autonomy and AI, and the failure case studies that produced the rules.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

- **flightsw-gnc-verification-ground-and-autonomy** — GNC, Verification and Validation, Ground Segment, Autonomy, and Failure Cases (§12–§16): GNC Software; Verification and Validation; Ground Segment; Autonomy and Onboard AI; Failure Case Studies.
