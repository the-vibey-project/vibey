# Engineering Process Plugin

Skills for requirements engineering, SDLC, process frameworks, and research methodology.

- **requirements-gathering**: Structured interviews, Event Storming, Example Mapping, NFRs, AI-assisted RE, EU AI Act obligations.
- **sdlc-practices**: SDLC model selection, TDD, trunk-based dev, CI/CD, DORA metrics, DevSecOps, observability.
- **process-engineering**: Agile/Scrum/Kanban/SAFe/PMBOK evidence-based guide with flow metrics and OKRs.
- **research-methodology**: Turabian 9th edition citations, research design, statistical rigor, open science, and systematic review.
