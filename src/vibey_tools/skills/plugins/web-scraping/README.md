# Web Scraping Plugin

A technical and professional reference for web data collection: the legal and regulatory landscape from the CFAA and the hiQ line through contract exposure, the DMCA §1201 shift, copyright and GDPR to the EU AI Act; when not to scrape and what to do instead; robots.txt and the emerging crawl-permission layer; how the modern web serves data; the tool ladder; parsing and extraction; bot detection and why you are blocked; scale, reliability and data quality; storage and operations; operational ethics; scraping for AI and RAG; and building a site that handles crawlers well.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **scraping-legal-landscape-and-permissions** — The Legal Landscape, Whether to Scrape, and the Permission Layer (§0–§3): Routing; The Legal Landscape; Should You Scrape At All?; robots.txt and the Permission Layer.
- **scraping-tooling-extraction-and-blocking** — How the Web Serves Data, the Tool Ladder, Parsing, and Blocking (§4–§7): How the Web Serves Data; The Tool Ladder; Parsing and Extraction; Why You're Getting Blocked.
- **scraping-scale-reliability-and-data-quality** — Scale and Reliability, Data Quality, and Storage and Operations (§8–§10): Scale and Reliability; Data Quality; Storage and Operations.
- **scraping-ethics-ai-corpora-and-site-defense** — Operational Ethics, Scraping for AI and RAG, and If You Run a Site (§11–§13): Operational Ethics; Scraping for AI and RAG; If You Run a Site.
- **scraping-reference** — Anti-Patterns, Contested Questions, Currency, and Canon (§14–§19): Anti-Patterns; Contested Questions; Currency Snapshot; The Canon; Quick Reference; Sources and Method.
