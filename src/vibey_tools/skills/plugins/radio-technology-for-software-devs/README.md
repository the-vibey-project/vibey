# Radio Technology for Software Developers Plugin

Radio for engineers who write software and keep hitting problems the abstraction does not explain: why wireless breaks software intuitions, spectrum and bands, the link budget, the range/rate/power triangle, antennas, propagation and fading, noise and interference, modulation and Shannon's limit, spread spectrum, OFDM, coding and retransmission, multiple access, SDR and IQ sampling, the DSP essentials and the SDR toolchain, the protocol stack from Wi-Fi and BLE through LPWAN, Thread and Matter to GNSS, the regulatory constraints, wireless security, and how to debug an RF problem from the software side.

One reference, split into 6 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
