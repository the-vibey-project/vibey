# Compliance Frameworks

Skills for achieving and maintaining security compliance across major frameworks.

## Skills

- **nist-800-171** — NIST SP 800-171 Rev 3 CUI protection requirements
- **pci-dss-v4** — PCI-DSS v4.0 cardholder data environment compliance
- **soc2-compliance** — SOC 2 Type II Trust Services Criteria
- **cmmc-cui** — CMMC 2.0 and CUI handling for defense contractors
- **owasp-samm** — OWASP SAMM v2 software assurance maturity model
