# Currency Research

Skills for the scheduled audit that keeps this marketplace's dated claims honest — checking
whether new developments in a field warrant changing what a reference says, and packaging the
result as a reviewable pull request.

Used by the `Currency research` workflow, which runs weekly over a rotating slice of the
marketplace. The skills are general enough to apply to any evidence-grounded knowledge base,
not just this one.

## Skills

- **research-currency-audit-method** — The durability tiers, what counts as a finding, the decision procedure, scoping a run, and why the default answer is no change
- **research-search-and-source-quality** — Constructing searches, source tiers, dating a claim, recording provenance, and the fabrication failure mode
- **research-editing-a-reference-skill** — SKILL.md anatomy, shared section numbering, the cross-reference annotation rule and the cross-document citations that must stay bare, byte discipline, and the manifests that mirror an edit
- **research-weekly-pull-request** — Branch and commit conventions, the PR body that lets a reviewer check sources without redoing the research, the no-change outcome, and the scope limits an unattended run must respect
