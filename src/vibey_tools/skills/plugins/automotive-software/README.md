# Automotive Software Plugin

Vehicle software engineering as practised: what makes it different, E/E architecture and the move to zonal and central compute, CAN and Automotive Ethernet, AUTOSAR Classic and Adaptive, real-time scheduling, functional safety under ISO 26262 including ASIL decomposition and SOTIF, cybersecurity under ISO/SAE 21434 and the UN regulations that gate market access, diagnostics, flashing and OTA, ADAS and autonomy including the validation problem, process and toolchain, testing, the domains, and supply chain reality.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.
