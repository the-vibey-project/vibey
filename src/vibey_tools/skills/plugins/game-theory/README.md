# Game Theory Plugin

Game theory as an analytical tool, with explicit attention to what it assumes and where it breaks: the framework and what rationality actually requires, representations, dominance, Nash equilibrium and its common misreadings, the classic games, zero-sum and minimax, sequential and repeated games, incomplete information, bargaining, cooperative theory, mechanism design and auctions, matching markets, evolutionary game theory, the empirical failures, and the computational side.

One reference, split into 5 skills along its section groups so a task loads only the part it needs. Section numbers (§N) are shared across the set and cross-references into a sibling skill are written as §N → `skill`. Reference, not tutorial: sections are independent, every claim is tagged by how durable it is (stable fundamentals vs. versioned specifics vs. genuinely contested questions), and a currency snapshot (verified August 2026) flags what goes stale first.

## Skills

- **gametheory-framework-nash-and-classic-games** — The Framework, Representations, Dominance, Nash Equilibrium, and the Classic Games (§0–§5): Routing; The Framework; Representations; Dominance; Nash Equilibrium; The Classic Games.
- **gametheory-zero-sum-sequential-repeated-and-information** — Zero-Sum and Minimax, Sequential, Repeated, and Incomplete-Information Games (§6–§9): Zero-Sum and Minimax; Sequential Games; Repeated Games; Incomplete Information.
- **gametheory-bargaining-cooperative-mechanism-design-and-matching** — Bargaining, Cooperative Theory, Mechanism Design and Auctions, and Matching Markets (§10–§13): Bargaining; Cooperative Game Theory; Mechanism Design and Auctions; Matching Markets.
- **gametheory-evolutionary-empirical-limits-and-computation** — Evolutionary Game Theory, Empirical Failures, and Computation (§14–§16): Evolutionary Game Theory; Where the Theory Fails Empirically; Computational Game Theory.
- **gametheory-reference** — Misconceptions, Formulas, and Canon (§17–§21): Misconceptions; Formulas and Facts; Books; Quick Reference; Method.
