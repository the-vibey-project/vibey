# FOSS documentation

Inventory behavior from code, tests, configuration, packaging, workflows, releases, and
public surfaces. Maintain README, changelog, license, conduct, contribution, security,
support, governance, architecture, operations, troubleshooting, testing, release, ADR,
and agent documentation. Follow `references/completeness.md`. Never invent functionality.

## Resources
- `references/completeness.md` is the completeness and freshness checklist.
