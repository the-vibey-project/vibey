**A Bitbucket forge adapter** (`vibey_gh/forge_bitbucket.py`, behind `ForgeAdapterInterface`; second slice of #298, covering #1618 and #1619). `BitbucketForge` speaks every forge-neutral verb on `BitbucketTransport`: pull requests, issues, comments, a pull request's reviewer verdicts, commit statuses (an unfinished status stays unfinished), squash/merge/rebase merges, and branch protection as a pair of `force` and `delete` branch restrictions. The verbs Bitbucket Cloud cannot express (releases, labels, an administrator merge) answer a named `NotSupported` problem and make no API call, so a forge that cannot be asked never reads as one that answered "nothing". It is tested offline against a scripted transport. Nothing selects it yet: `kind = "bitbucket"` is still refused at config load (#1617).
