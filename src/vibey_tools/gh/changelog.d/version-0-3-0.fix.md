* **vibey-gh is numbered 0.3.0, not 1.73.0:** `pyproject.toml` and `vibey_gh.__version__` move to the project's pre-1.0 number, with the rest of the family. The number identifies the package inside the `vibey-engine` wheel and is not a release an index serves, so the fallback-pin resolution (which reads the installed distribution's version, not this one) is unchanged. **Migration:** anything that compared `vibey_gh.__version__` against `1.x` must stop doing so.
