* **The managed hooks no longer run code a branch chose:** `vibey_gh_self()` in `commit-msg` and `pre-push` read `[install] self_source` from the tracked `.vibey-gh.toml` and defaulted to `.`, so a branch that added a root `pyproject.toml` named `vibey-gh` beside a `vibey_gh/` directory (or edited that key) had its own code executed when a developer committed or pushed. The hooks now read `vibey-gh.self-source` from the clone's local git config, and an unset key means not self-hosted. `vibey-gh install` copies an explicitly declared `[install] self_source` into it, never overwrites a different value, and `installed(local=True)` reports a missing or differing one. The key is hyphenated because git rejects `_`. **Migration:** re-run `vibey-gh install` once per clone; until then a self-hosting clone runs the `vibey-gh` on `PATH`. #1292.
