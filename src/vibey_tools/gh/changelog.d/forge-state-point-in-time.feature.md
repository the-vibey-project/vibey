**`vibey-gh forge-state` answers "what did this object look like then?" from a snapshot** (#1574, part of #136). Given a snapshot directory, an issue number (or a class and native id) and a moment, it prints the latest record's payload at or before that moment, with its `captured_at` and seal and when the latest capture began. It reads only the snapshot's own files, refuses a damaged class file instead of answering from it, and keeps two outcomes apart that must never be merged: an object first recorded later than the moment, and an object the snapshot never recorded. Neither is reported as "did not exist". Behind it, `JsonlSnapshotStore.records()` is the one checked reader of a class file, and `ForgeStateQuery` has its own interface.
