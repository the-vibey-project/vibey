`[install] pin` holds every rendered `pip install <fallback_package>` pin at an exact release (`pin = "4.6.0"`), outranking the repository's own `[project] version` and the installed release. It is for a renumbering, when the version the pin would be rendered from is not on an index yet: pinning to it would break every install, and floating would give privileged workflows whatever is newest. It needs `pin_version = true` and accepts only a release such as `4.6.0`; a version bump does not move it. Unset, nothing changes.
