`[rulesets.<branch>]` takes `absent_rules`, a list of rule types that must not exist on the ruleset. `vibey-gh rulesets` used to carry forward every live rule the declaration did not name, so a rule added by hand could never be removed from the repository as code; a listed type is now dropped from the payload and reported as `removed rule(s)`, and `vibey-gh rulesets --check` fails while it is live. Declaring a type and listing it absent is refused at load.
