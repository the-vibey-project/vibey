`[marketplace] packaged` renders a second copy of the root marketplace for a package that ships every member's plugin trees side by side under one `plugins/` folder: every `./` source becomes `./plugins/<the source folder's last segment>`, two plugins whose folders share that name are refused, `vibey-gh marketplace` writes both files and `check` reports drift in either. vibey's wheel uses it, so every install carries exactly the root's plugins rather than one member's. Unset, nothing changes.
