**The Linux device fingerprint now sees AMD GPUs** (`LinuxDeviceProbe` in `vibey_gh/slots.py`; part of #1116). A host with an AMD card used to be fingerprinted as `accelerator: none` because only `nvidia-smi` was asked. The probe now also reads `/sys/class/drm/cardN/device/` (vendor `0x1002`, `mem_info_vram_total`, and `product_name` when the card has one), tries every card index because the discrete card is often not `card0`, and leaves out a card whose VRAM figure it cannot read rather than guessing one. NVIDIA and AMD cards on one host are listed together. Tested against file text only; it has not been run on a real AMD host.
