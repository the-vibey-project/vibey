**`vibey-gh forge-snapshot --forge KIND` reads a forge other than GitHub, into the same envelope** (#1572, part of #136). `--forge forgejo` (or `gitlab`, `bitbucket`) captures through the adapter `[platform]` selects, with `--repo` or `[platform] repository` naming the repository. A bare `forge-snapshot` still reads GitHub. The record, the manifest and each manifest class entry now have declared field lists (`ENVELOPE_FIELDS`, `MANIFEST_FIELDS`, `CLASS_ENTRY_FIELDS`), and a test holds a GitHub capture and a Forgejo capture to them. A class the adapter cannot list is `could-not-look`, never an empty class; a `review` read through an adapter is normalised to four keys, which the reference now says.
