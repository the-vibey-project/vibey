**`vibey-gh tidy` surveys a Bitbucket repository** (fourth slice of #298, #1620). The clean-repo survey runs against `BitbucketForge`, and a forge that answers with a `NotSupported` problem (Bitbucket has no release object) is no longer reported as a class the survey "could not judge": there is no draft release to leave behind, so that is an answer, not a failure to look. A forge that cannot be asked at all (a 401, a timeout) is still reported, and its merged branches are still left unjudged. `NotSupported.is_problem` tells the two apart.
