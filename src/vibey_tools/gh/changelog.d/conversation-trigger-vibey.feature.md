**The conversation's default trigger is now `@vibey`, and `@vibey-gh` is a legacy handle that is still answered, with a warning** (#1589, part of #145). `[conversation] legacy_triggers` (default `["@vibey-gh"]`) names handles that still address the automation: a comment that uses one is answered as before, `conversation evaluate` carries a `warning` naming the trigger to use instead, and the workflow raises it as an annotation. The rendered workflow's cheap filter admits the trigger and every legacy handle, so the old handle reaches the evaluator. Set `legacy_triggers = []` to stop answering the old handle. A repository that wrote `trigger = "@vibey-gh"` explicitly keeps that trigger; only the default moved.
