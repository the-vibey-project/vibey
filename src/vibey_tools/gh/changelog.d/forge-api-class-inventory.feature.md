**A forge snapshot is now held to what the forge's API exposes** (#1571, part of #136). `vibey_gh/data/forge-api-classes.json` lists, per forge, every repository-scoped group its API description publishes, mapped to a forge-neutral class. Each capture compares that list with the classes it captures and excludes, records the result as `inventory` in `manifest.json` (the list's digest, whether it was read in full, and the `unaccounted` classes), and is not `complete` while any class the API exposes has no home. Twelve classes GitHub or Forgejo expose that were in neither list are now excluded with a reason. The GitHub list was read in full from GitHub's OpenAPI description; the Forgejo list was not (its swagger document was cut short) and is marked `verified: false` rather than presented as read. A forge nobody has listed reports `unaccounted: null`, not an empty list.
