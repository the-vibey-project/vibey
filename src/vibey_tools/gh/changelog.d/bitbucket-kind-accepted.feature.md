**`[platform] kind = "bitbucket"` now loads** (third slice of #298, #1617). `ForgeSelector` builds a `BitbucketForge` on a `BitbucketTransport` for it: `host` defaults to Bitbucket Cloud's `api.bitbucket.org` (or names a self-managed host), `repository` is `workspace/repo-slug`, and `token_env` names the environment variable holding an access token or `username:app-password`. Every forge the standard names now has an adapter, so `ADAPTED_PLATFORM_KINDS` equals `ForgeKind`; the "not implemented yet" refusal remains for any future kind added without one.
