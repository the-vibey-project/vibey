# Continuation prompts

> [!IMPORTANT]
> **Bottom Line Up Front (BLUF):** These pages are self-contained prompts for picking vibey up
> cold, with no memory of past sessions. Pick the page for the job, paste its `text` block into
> any capable agent whose working directory is a clone of this repository, and it says what to
> read, what to run, what never to do, and how to know the work is done. Lost everything?
> Start with [Rebuild](rebuild.md).

A project is alive while someone can pick it up. These prompts are written so that **anyone
with any capable AI agent**, including an open-weights model served by Ollama, can pick
vibey up cold: no memory of past sessions, no knowledge of who built it, no access to anyone
who did. Each one is self-contained. Paste it into an agent whose working directory is a
clone of this repository, and it says what to read, what to run, what never to do, and how
to know the work is done. Sub-doctrine 10.l is the law they keep, and
[ADR-0080](../architecture/decisions/0080-continuation-prompts.md) is how.

They are not left to rot. `scripts/continuation_prompts.py check` runs on every pull
request and fails when a prompt names a file, command or workflow that no longer exists, when
a lane or an agent skill is covered by no prompt, or when a page's generated state is stale.

## How GitHub runs them

The [Continuation prompts](https://github.com/the-vibey-project/vibey/actions/workflows/continuation-prompts.yml)
workflow (`.github/workflows/continuation-prompts.yml`) runs every Monday at 03:41 UTC and by
hand. Each week it keeps every scheduled workflow enabled, refreshes these pages, and runs
the **weekly** prompts on a GitHub-hosted CPU runner with an open-weights model (`qwen3:8b`,
declared in `scripts/continuation_prompts.toml` `[run]`). The *act* prompts may open draft
pull requests; the *drill* prompts verify that every instruction still holds and report what
does not. Nothing it runs can merge, approve, release, delete, or touch a ruleset or a secret.

Three prompts are **daily**: they are not in the weekly run, and a daily lane dispatches them
to the same workflow when it has work for them.

| Prompt | Dispatched by | When |
|---|---|---|
| [Keep develop green](keep-green.md) | `.github/workflows/self-healer.yml` | after its scripted repairs and re-runs leave something red |
| [Keep the documentation true](docs.md) | `.github/workflows/docs-updater.yml` | after its generators have run |
| [Work the backlog](backlog.md) | `.github/workflows/backlog-killer.yml` | once per slot, for the issue it picked; **paused since 2026-10-29** |

[Work the backlog](backlog.md) is the one declared exception to "GitHub-hosted CPU only"
(ADR-0083, amended 2026-10-09): it runs on the operator's own machine, and only while that
machine's heartbeat is fresh (`[run.sovereign]` in `scripts/continuation_prompts.toml`).
The [Chat](chat.md) prompt runs whenever a trusted person asks for it.

## If everything else is gone

Start with [Rebuild](rebuild.md). It assumes nothing survives but a copy of the code — a
clone, a release's source distribution, or the book — and walks back from there.

## Say it in one line

vibey's continuation prompts let any capable agent pick the project up cold, and a check on every pull request keeps each one true.
