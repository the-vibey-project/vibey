Part of the **QwenStorm for 3.0.0**. A local sovereign lane (qwenloop until ADR-0046's rename lands) implements this issue; the result is reviewed and verified before it becomes a pull request.

## Why
Sub-doctrine 8.b (`src/vibey_tools/gh/docs/doctrines.md:138-139`) makes self-hosted Forgejo
the default forge, with GitHub and GitLab declared-only; `[platform] kind` defaults to
`forgejo` (`vibey_gh/config.py:288`). `vibey_gh/issue_automation.py` reads issues through
`github_state.gh_json` + `github_state.repository()` (`fetch_issue` 265-278,
`eligible_issues` 402-421) and creates labels with `gh label create --force`
(`ensure_labels` 383-399). `vibey_gh/conversation.py` reads threads and review comments the
same way (`fetch_subject` 369-386, `ConversationThread._review_comment` 202-217) and replies
with `gh issue comment --repo` (`reply` 414-431). None of them reads `[platform]`.

The conversation code also decides "is this a pull request?" from GitHub's URL shape
(`/pull/N`, `is_pull_request` 163-174). Forgejo's pull URLs are `/pulls/N`, so on the
sovereign default every pull request would read as an issue; the adapter's `isPullRequest`
flag (#336) answers the question on every forge.

When a paid forge is declared, 8.b says it "relays through the sovereign host rather than
replacing it" (`doctrines.md:179-184`). That relay belongs behind `ForgeAdapterInterface`;
this lane keeps every call on the interface.

## Conventions this lane relies on (everything needed is here)
**C1 — the adapter contract.** Every adapter verb answers `(value, problem)`. `problem` is
`""` exactly when the forge answered; otherwise `value` is the empty value for its type and
`problem` is one sentence. No verb raises for a failed call, a missing client, a non-2xx
status or unreadable output (`vibey_gh/interfaces/forge_adapter_interface.py:9-16`). A verb
a forge has no equivalent for answers `(<empty>, NotSupported(kind, verb, reason).problem)`,
text `f"{kind.value} does not support {verb}: {reason}"`; the caller reports it like any
other problem (10.f), never special-cases a forge, never skips silently.

**C5 — facts are mappings.** `issue_facts` returns `number, title, body, state
("OPEN"|"CLOSED"), author, labels, comments, createdAt, url` (Forgejo adds `pull_request`
only when the number is a pull request, which `evaluate` already skips); `subject_facts`
returns `number, title, body, state, author, labels, comments, url, isPullRequest (bool)`;
`review_comment` returns `id, body, user ({"login"}), path, line, original_line, diff_hunk,
pull_request_url`. `evaluate` and `context` are not changed.

**C6 — how these modules call the adapter.**
1. Obtain: each public function (and `ConversationThread`) gains a keyword-only last
   parameter `forge: ForgeAdapterInterface | None = None` and resolves with
   `ForgeSelector().resolve(forge, cfg)` (or `.resolve(forge)` without a `cfg`); #332
   returns the injected forge, else `select(cfg)`, else `select(load_config())`.
2. Bind where today's code called `github_state.repository()`:
   `name, problem = forge.repository_name()`; `if problem: raise RuntimeError(problem)`;
   `bound = forge.for_repository(name)`. Once per public call.
3. A site that raised keeps raising; a site that returned a bool keeps returning it; a
   site that ignored a result keeps ignoring it.

**C7 — tests (amended for 9.b and the fakes standard).**
- 100% line and branch coverage of `vibey_gh` (`src/vibey_tools/gh/pyproject.toml:64-71`).
  Focused runs need `--no-cov`.
- Substitute only at a declared seam: pass `forge=` (or the `ConversationThread`
  constructor's `forge`). Never `monkeypatch.setattr` a module or class attribute
  (`ia.fetch_issue`, `ia.upsert_state`, `cv.github_state.gh_json`, `subprocess.run`), never
  `mock.patch` or `MagicMock`. `monkeypatch.setenv/delenv/chdir` are fine.
- `RecordingForge` (#332): each scripted verb returns its value (or calls it, if callable);
  `repository_name()` defaults to `("o/r", "")`; `for_repository(name)` records and returns
  itself; `.calls` lists `(verb, *args, *sorted(kwargs.items()))`; an unscripted verb raises
  `AttributeError`.
- GitHub argv proofs: the conftest `scripted_gh` (`test/conftest.py:51-84`, sets
  `GH_REPO=o/r`) or `fake_gh` (87-156) fixtures — real `gh` executables first on PATH —
  with `forge=GitHubForge(root=tmp_path)` injected.
- No test leaves the machine unless marked `network` (`test/conftest.py:22-40`). Never touch
  `test/conftest.py`.

**C8 — the formatter trap.** Checked by both `black --line-length 100` + `isort` and the root
`ruff format`. Keep lines ≤ 100 columns (≤ 95 with nested calls); bind long comparisons to a
local before asserting; no implicit string concatenation that would fit on one line; one
argument per line with a trailing comma in multi-line calls; no backslash continuations.
