Part of the **QwenStorm for 3.0.0**. A local sovereign lane (qwenloop until ADR-0046's rename lands) implements this issue; the result is reviewed and verified before it becomes a pull request.

## Why
Sub-doctrine 8.b (`src/vibey_tools/gh/docs/doctrines.md:138-139`) makes self-hosted Forgejo
the default forge, with GitHub and GitLab declared-only; `[platform] kind` already defaults
to `forgejo` (`vibey_gh/config.py:288`). `vibey_gh/merge_train.py` still runs `gh` directly at
14 sites through two private runners, `_gh_json` (`merge_train.py:67-73`) and `_gh` (76-81),
plus two direct `subprocess.run(["gh", …])` calls (269-282, 378-385). It ignores `[platform]`
and would drive GitHub on a repository whose declared forge is the sovereign default. After
the forge-adapter Wave 1 (#332-#338) every verb it needs exists on `ForgeAdapterInterface`.

The merge train is live release machinery: this repository's workflows run
`vibey-gh merge-train` to squash feature pull requests into `develop` (CLAUDE.md, ADR-0028).
Once this lane merges, the train follows `[platform]`, so this repository must already
declare GitHub (see **Depends on**).

When a paid forge is declared, 8.b says it "relays through the sovereign host rather than
replacing it" (`doctrines.md:179-184`). That relay belongs behind `ForgeAdapterInterface` (an
adapter, not yet specified); this lane keeps every forge call on the interface so a relay can
be slotted in without touching this module again.

## Conventions this lane relies on (everything needed is here)
**C1 — the adapter contract.** Every adapter verb answers `(value, problem)`. `problem` is
`""` exactly when the forge answered; otherwise `value` is the empty value for its type
(`None`, `()`, `frozenset()`, `False`, `{}`) and `problem` is one sentence. No verb raises for
a failed call, a missing client, a non-2xx status or unreadable output
(`vibey_gh/interfaces/forge_adapter_interface.py:9-16`). A verb a forge has no equivalent for
answers `(<empty>, NotSupported(kind, verb, reason).problem)`, text
`f"{kind.value} does not support {verb}: {reason}"`. The caller reports it like any other
problem (10.f); it never special-cases a forge and never skips silently.

**C5 — facts are mappings.** `change_request_facts` returns a `dict` whose keys are the ones
`judge` already reads: `number`, `title`, `body`, `state`, `isDraft`, `mergeable`,
`mergeStateStatus`, `reviewDecision`, `statusCheckRollup`, `author`, `labels`, `headRefOid`,
`headRefName`, `baseRefName`, `isCrossRepository`, and `changedFiles` (omitted when the
forge does not count). `judge` is not changed.

**C7 — tests (amended for 9.b and the fakes standard).**
- The tenant floor is 100% line and branch coverage of `vibey_gh`
  (`src/vibey_tools/gh/pyproject.toml:64-71`). Focused runs need `--no-cov`.
- Substitute only at a declared seam: pass `forge=`. Never `monkeypatch.setattr` a module
  or class attribute (`merge_train._gh_json`, `merge_train.pull_request`,
  `ForgeSelector.resolve`, `subprocess.run`), never `mock.patch` or `MagicMock`.
  `monkeypatch.setenv/delenv/chdir` are fine: the environment is a declared seam.
- `RecordingForge` (`test/forge_doubles.py`, #332): `RecordingForge(change_request_facts=
  (facts, ""), …)`; each scripted verb returns its value (or calls it, if callable);
  `repository_name()` defaults to `("o/r", "")`; `for_repository(name)` records and returns
  itself; `.calls` lists `(verb, *args, *sorted(kwargs.items()))`; an unscripted verb raises
  `AttributeError`. Import with `from forge_doubles import RecordingForge`.
- GitHub argv proofs use the conftest `fake_gh` fixture (`test/conftest.py:87-156`: a real
  `gh` executable put first on PATH; `script({...})`, `calls()`, `invocations()`) with
  `forge=GitHubForge(root=…)` injected.
- No test leaves the machine unless marked `network` (`test/conftest.py:2`, 22-40).
- Never touch `test/conftest.py`.

**C8 — the formatter trap.** The tenant is checked by both `black --line-length 100` +
`isort` and the root `ruff format` (line length 100). Keep lines ≤ 100 columns (≤ 95 with
nested calls); bind a long comparison to a local before asserting it; no implicit string
concatenation that would fit on one line; one argument per line with a trailing comma in
multi-line calls; no backslash continuations. If the two formatters disagree, restructure
the line.
