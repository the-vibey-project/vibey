## §36 Free and digital tools

| Tool | What it's for |
| --- | --- |
| **STEPBible** (Tyndale House, Cambridge) | Free original-language Bible with lexicons and morphology |
| **NET Bible** (netbible.org) | Translation with \~60,000 translators' notes |
| **NTVMR** (ntvmr.uni-muenster.de) | NT manuscript images, the Liste, ECM, transcriptions |
| **Codex Sinaiticus Project** | The full codex online |
| **Leon Levy DSS Digital Library** | Dead Sea Scrolls images |
| **Center for the Study of New Testament Manuscripts** (CSNTM) | High-resolution NT manuscript images |
| **Academic Bible** (academic-bible.com, German Bible Society) | Read NA28, BHS, Rahlfs, Vulgate online |
| **Perseus Digital Library** | Classical texts and LSJ |
| **Open Scriptures Hebrew Bible / ETCBC** | Open morphological data |
| **Accordance / Logos** | Commercial research platforms (BHQ, ECM, lexicons) |
