## §9 How copying errors happen

### §9.1 Unintentional changes (the great majority)

| Error | What happens | Example pattern |
| --- | --- | --- |
| **Haplography** | Writing once what should be written twice | Skipping a repeated letter or word |
| **Dittography** | Writing twice what should be written once | Duplicated syllable or line |
| **Homoioteleuton / homoioarcton** | The eye jumps from one ending (or beginning) to an identical one further down, omitting everything between | Very common cause of omitted lines |
| **Parablepsis** | General "looking aside" error |  |
| **Letter confusion** | Similar shapes: Hebrew ד/ר (d/r), ו/י (w/y), ב/כ; Greek uncial Ε/Θ/Ο/Σ | 2 Samuel vs 1 Chronicles name differences |
| **Itacism** | In later Greek, several vowels and diphthongs came to sound alike (η, ι, ει, οι, υ) | "we" (ἡμεῖς) vs "you" (ὑμεῖς) — dozens of variants |
| **Metathesis** | Transposed letters or words |  |
| **Mishearing** | When copying by dictation |  |
| **Wrong word division** | Early Greek manuscripts were written without spaces (*scriptio continua*) |  |

### §9.2 Intentional changes

Scribes also changed texts on purpose, usually thinking they were *correcting* them: **harmonization** (making Mark match Matthew, or a quotation match the Septuagint), **clarification** (adding "Jesus" where the text says "he"), **grammatical smoothing**, **conflation** (combining two known readings), liturgical additions (the doxology at the end of the Lord's Prayer in Matthew 6:13), and occasionally **theologically motivated** changes. Bart Ehrman's *The Orthodox Corruption of Scripture* (1993) argued that proto-orthodox scribes altered texts in christological controversies; critics (e.g., Daniel Wallace, Michael Holmes) accept that some such changes happened but dispute how many and how significant. **\[contested in degree\]**
