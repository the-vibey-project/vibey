## §30. Learning and Resources

| Source | Why |
|---|---|
| **A local class or makerspace** | ⚠️ **Machinery genuinely needs supervised first use** |
| **Hoadley, *Understanding Wood*** | ⚠️ **§3 → `shop-materials-safety-reading-wood-and-stock`. The book on wood as a material** |
| **Sellers / Schwarz / Cosman (hand tools)** | ⚠️ **§6–§7 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, and free video is genuinely good here** |
| **Fine Woodworking archive** | Decades of tested technique |
| **Machinery's Handbook** | ⚠️ **§15–§25 → `shop-metalwork-cutting-drilling-and-machining`, `shop-welding-forging-heat-treatment-and-shop-setup`. The trade's single reference** |
| **Sparey, *The Amateur's Lathe*** | ⚠️ **§18 → `shop-metalwork-cutting-drilling-and-machining`, classic and still excellent** |
| **Hall / Workshop Practice Series** | ⚠️ **Small, cheap, focused volumes** |
| **AWS welding handbooks / *Welding For Dummies*** | §19 → `shop-welding-forging-heat-treatment-and-shop-setup` at both ends |
| **Lorena Bull / blacksmithing guilds** | §21 → `shop-welding-forging-heat-treatment-and-shop-setup` |
| **OSHA 1910.1026 and CPL 02-02-074** | ⚠️ **§27.2, primary** |
| **CPSC docket CPSC-2011-0074** | ⚠️ **§27.1, primary** |
| **Manufacturer manuals** | ⚠️ **Actually read them; the guards exist for reasons** |
