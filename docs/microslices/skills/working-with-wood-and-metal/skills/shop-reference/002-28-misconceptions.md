## §28. Misconceptions

| Misconception | Correction |
|---|---|
| A sharp tool is more dangerous | ⚠️ **Dull needs force; force loses control** (§7 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Sharpening is an advanced skill | ⚠️ **It's the prerequisite for everything** (§7 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Hardwood means hard | ⚠️ **Botanical, not mechanical. Balsa is a hardwood** (§3 → `shop-materials-safety-reading-wood-and-stock`) |
| Kiln-dried wood is stable | ⚠️ **It moves with humidity forever** (§3 → `shop-materials-safety-reading-wood-and-stock`) |
| Measure carefully and it'll fit | ⚠️ **TRANSFER instead of measuring where you can** (§5 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Use the fence and mitre gauge together | ⚠️ **Traps the offcut. Classic kickback cause** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| The blade guard is the main protection | ⚠️ **The RIVING KNIFE prevents kickback** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Flesh-detection makes a saw safe | ⚠️ **It addresses contact, not kickback** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, §27.1) |
| Clamp harder to close the joint | ⚠️ **A joint needing force is cut wrong** (§11 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Glue squeeze-out will sand off | ⚠️ **It blocks finish. Remove it wet** (§11 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Gloves protect you around machines | ⚠️ **NEVER near rotating machinery** (§2 → `shop-materials-safety-reading-wood-and-stock`, §18 → `shop-metalwork-cutting-drilling-and-machining`) |
| Push harder to cut metal faster | ⚠️ **Rubbing work-hardens; then nothing cuts** (§14 → `shop-metalwork-cutting-drilling-and-machining`) |
| Cutting fluid is optional | ⚠️ **It's cooling. Heat destroys edges and tempers** (§14 → `shop-metalwork-cutting-drilling-and-machining`) |
| More thread engagement is stronger | ⚠️ **~75% is standard; more just snaps taps** (§17 → `shop-metalwork-cutting-drilling-and-machining`) |
| Mild steel can be hardened | ⚠️ **Not enough carbon** (§22 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Hardened steel is ready to use | ⚠️ **Brittle until tempered. Never skip it** (§22 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| A cutting disc can grind a little | ⚠️ **Side loading shatters it** (§2 → `shop-materials-safety-reading-wood-and-stock`, §16 → `shop-metalwork-cutting-drilling-and-machining`) |
| Arc eye happens immediately | ⚠️ **Symptoms hours later. Bystanders too** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| A dust mask handles welding fume | ⚠️ **It doesn't. Extraction first** (§26 → `shop-welding-forging-heat-treatment-and-shop-setup`, §27.2) |
| The SDS shows no carcinogen, so it's fine | ⚠️ **The arc CREATES Cr(VI)** (§27.2) |
| A shop vac controls wood dust | ⚠️ **It misses the dangerous fine fraction** (§26 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Wood dust is a nuisance | ⚠️ **Classified carcinogen; hardwood especially** (§2 → `shop-materials-safety-reading-wood-and-stock`) |
| Welding fixes a bad fit | ⚠️ **Fit-up determines weld quality** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Weld it all at once for strength | ⚠️ **Distortion. Tack and stagger** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
