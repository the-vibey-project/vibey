## §31. Quick Reference

### 31.1 Picker
| Problem | Where |
|---|---|
| Plane tears out the grain | ⚠️ **Wrong direction, or use a scraper** (§3 → `shop-materials-safety-reading-wood-and-stock`, §6 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Nothing fits despite careful measuring | ⚠️ **Four-square first; transfer, don't measure** (§4 → `shop-materials-safety-reading-wood-and-stock`, §5 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Joint too tight to assemble | ⚠️ **It'll split when glued. Pare it** (§10 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, §11 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Finish has pale patches | ⚠️ **Glue residue** (§11 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Saw burns the wood | ⚠️ **Dull blade, slow feed, or misaligned fence** (§8 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, §9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Workpiece thrown back at me | ⚠️ **Kickback. Riving knife, stance, technique** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`) |
| Drill wanders | ⚠️ **Centre punch** (§17 → `shop-metalwork-cutting-drilling-and-machining`) |
| Tap snapped | ⚠️ **Too much engagement, no fluid, not square** (§17 → `shop-metalwork-cutting-drilling-and-machining`) |
| Tool stops cutting stainless | ⚠️ **Work-hardened. Sharp tool, positive feed** (§13 → `shop-metalwork-cutting-drilling-and-machining`, §14 → `shop-metalwork-cutting-drilling-and-machining`) |
| Machined part moved after cutting | ⚠️ **Residual stress. Rough, rest, finish** (§14 → `shop-metalwork-cutting-drilling-and-machining`) |
| Chatter on the lathe | ⚠️ **Rigidity, centre height, feed** (§18 → `shop-metalwork-cutting-drilling-and-machining`) |
| Weld is porous | ⚠️ **Contamination or lost shielding gas** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Work distorted after welding | ⚠️ **Shrinkage. Tack, stagger, clamp** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Braze won't flow | ⚠️ **Not hot enough, wrong flux, or gap too wide** (§20 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Hardened part cracked | ⚠️ **Wrong quench, or never tempered** (§22 → `shop-welding-forging-heat-treatment-and-shop-setup`) |
| Eyes gritty hours after welding | ⚠️ **Arc eye. Medical attention** (§19 → `shop-welding-forging-heat-treatment-and-shop-setup`) |

### 31.2 Before you start the machine
- [ ] ⚠️ **Eye protection on; hearing protection for anything loud** (§2 → `shop-materials-safety-reading-wood-and-stock`)
- [ ] ⚠️ **No gloves, loose sleeves, jewellery; hair tied** (§2 → `shop-materials-safety-reading-wood-and-stock`)
- [ ] Guards fitted; ⚠️ **riving knife in place** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`)
- [ ] ⚠️ **Workpiece clamped or properly supported** (§8 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, §17 → `shop-metalwork-cutting-drilling-and-machining`)
- [ ] Blade/bit sharp and correct for the material (§7 → `shop-woodworking-tools-sharpening-joinery-and-finishing`, §8 → `shop-woodworking-tools-sharpening-joinery-and-finishing`)
- [ ] ⚠️ **Push stick within reach; hands' path planned** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`)
- [ ] ⚠️ **Standing out of the line of fire** (§9 → `shop-woodworking-tools-sharpening-joinery-and-finishing`)
- [ ] Extraction running; ⚠️ **respirator if fine dust or fume** (§26 → `shop-welding-forging-heat-treatment-and-shop-setup`)
- [ ] Chuck key removed (§18 → `shop-metalwork-cutting-drilling-and-machining`)
- [ ] ⚠️ **Not tired, not rushing, not distracted** (§2 → `shop-materials-safety-reading-wood-and-stock`)
