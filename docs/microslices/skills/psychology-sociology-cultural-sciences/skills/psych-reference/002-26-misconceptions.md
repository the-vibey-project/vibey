## §26. Misconceptions

| Misconception | Correction |
|---|---|
| Most published psychology findings are solid | ⚠️ **~36% replicated in 2015; ~50–55% in recent estimates** (§1 → `psych-epistemic-situation-and-replication-reform`, §25.1) |
| The replication crisis means psychology is fake | ⚠️ **Preregistered studies replicated at 86%** (§1.2 → `psych-epistemic-situation-and-replication-reform`) |
| **Learning styles** (visual/auditory/kinesthetic) | ⚠️ **No support. Repeatedly tested, repeatedly failed** (§1.3 → `psych-epistemic-situation-and-replication-reform`) |
| Ego depletion / willpower as a fuel tank | ⚠️ **Failed large multi-lab replication** (§7 → `psych-perception-memory-learning-cognition-and-emotion`) |
| Power posing changes hormones and outcomes | ⚠️ **Did not replicate** (§1.3 → `psych-epistemic-situation-and-replication-reform`) |
| Social priming effects are established | ⚠️ **Broad replication failure as a programme** (§12 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| The Stanford Prison Experiment shows situational power | ⚠️ **Methodologically compromised; not usable evidence** (§12 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| The IAT measures your personal bias | ⚠️ **Poor individual reliability and weak behaviour prediction** (§12 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| MBTI tells you your personality type | ⚠️ **Poor reliability, false dichotomies, no predictive validity** (§10 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| People are introverts or extraverts | ⚠️ **Continuous distribution, not types** (§10 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Memory is a recording | ⚠️ **Reconstructive; false memories are readily created** (§5 → `psych-perception-memory-learning-cognition-and-emotion`) |
| Confident eyewitnesses are accurate | ⚠️ **Confidence tracks accuracy poorly, especially post-feedback** (§5 → `psych-perception-memory-learning-cognition-and-emotion`) |
| Re-reading and highlighting are good study methods | ⚠️ **Among the weakest. Use retrieval practice and spacing** (§5 → `psych-perception-memory-learning-cognition-and-emotion`) |
| We use 10% of our brains | ⚠️ **Straightforwardly false** |
| Left-brained / right-brained people | ⚠️ **Not a thing as popularly described** |
| It takes 21 days to form a habit | ⚠️ **No good basis; actual research found much longer and highly variable** (§6 → `psych-perception-memory-learning-cognition-and-emotion`) |
| Growth mindset produces large gains | ⚠️ **Effects far smaller than claimed** (§11 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Different therapies differ greatly in effectiveness | ⚠️ **Broadly similar, except exposure for anxiety/OCD** (§13 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Depression is a chemical imbalance | ⚠️ **Not supported as stated; medication can still work** (§13 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Heritability means fixed or unchangeable | ⚠️ **Population variance statistic; Flynn effect disproves it** (§14 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Heritability within groups explains gaps between groups | ⚠️ **Invalid inference. The most common error in the area** (§14 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Multiple intelligences is established | ⚠️ **Popular; not supported psychometrically** (§14 → `psych-development-personality-social-clinical-and-neurodiversity`) |
| Social construction means "not real" | ⚠️ **Constructed things have material consequences** (§16 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Broken windows policing is evidence-based | ⚠️ **Much weaker support than its policy uptake** (§21 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Severe punishment deters crime | ⚠️ **Certainty deters; severity much less** (§21 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Modernization inevitably produces secularization | ⚠️ **Substantially revised; one regional trajectory** (§22 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Hofstede's dimensions measure a person's culture | ⚠️ **Country-level aggregates; applying to individuals is an ecological fallacy** (§24 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Psychology findings describe humans | ⚠️ **They mostly describe WEIRD samples** (§24 → `psych-sociology-institutions-culture-and-the-weird-problem`) |
| Social media's harm to teens is settled | ⚠️ **Genuinely contested. See both cases** (§25.2) |
