## §29. Misconceptions

| Misconception | Correction |
|---|---|
| Plants get their mass from soil | ⚠️ **Mostly from CO₂ in air** (§4 → `agri-botany-and-plant-science`) |
| Fertilizer fixes poor growth | ⚠️ **Check pH and compaction first** (§4 → `agri-botany-and-plant-science`, §10 → `agri-soil-fertility-and-crop-production`) |
| More fertilizer, more yield | ⚠️ **Liebig — only the limiting nutrient responds** (§4 → `agri-botany-and-plant-science`) |
| Soil test is optional | ⚠️ **It's the cheapest input decision you'll make** (§11 → `agri-soil-fertility-and-crop-production`) |
| Soil is inert substrate | ⚠️ **It's a living system; biology does the work** (§10 → `agri-soil-fertility-and-crop-production`) |
| Tilling improves soil | ⚠️ **It costs structure, organic matter and mycorrhizae** (§10 → `agri-soil-fertility-and-crop-production`, §12 → `agri-soil-fertility-and-crop-production`) |
| A photo app can ID a plant for eating | ⚠️ **Not sufficient. Lethal lookalikes exist** (§7 → `agri-botany-and-plant-science`) |
| Common names identify plants reliably | ⚠️ **They don't. Use Latin names** (§7 → `agri-botany-and-plant-science`) |
| Organic means no pesticides | ⚠️ **It means restricted inputs; some approved ones are toxic** (§16 → `agri-soil-fertility-and-crop-production`) |
| Regenerative ag sequesters carbon at scale | ⚠️ **Saturates, reversible, hard to measure** (§16 → `agri-soil-fertility-and-crop-production`) |
| GM food safety is unsettled | ⚠️ **Safety is settled; agronomic/economic debates are real** (§15 → `agri-soil-fertility-and-crop-production`) |
| Cows digest grass | ⚠️ **Rumen MICROBES do. You feed the microbes** (§17 → `agri-livestock-nutrition-health-and-welfare`) |
| Cattle just eat human food | ⚠️ **Ruminants upgrade cellulose humans can't eat** (§17 → `agri-livestock-nutrition-health-and-welfare`) |
| Deworm everyone on a schedule | ⚠️ **That caused resistance. Use targeted treatment + refugia** (§20 → `agri-livestock-nutrition-health-and-welfare`) |
| Best genetics = best results | ⚠️ **Match the animal to the environment** (§21 → `agri-livestock-nutrition-health-and-welfare`) |
| Overgrazing is about animal numbers | ⚠️ **It's about TIME — recovery period** (§22 → `agri-livestock-nutrition-health-and-welfare`) |
| Efficient irrigation saves basin water | ⚠️ **It often increases total consumption** (§14 → `agri-soil-fertility-and-crop-production`) |
| Don't shoot does, protect the herd | ⚠️ **Antlerless harvest is the population control tool** (§24 → `agri-wildlife-management-and-hunting`) |
| Mature forest is great deer habitat | ⚠️ **Early successional habitat is** (§6 → `agri-botany-and-plant-science`, §24 → `agri-wildlife-management-and-hunting`) |
| Killing predators boosts game populations | ⚠️ **Usually smaller effect than habitat and weather** (§24 → `agri-wildlife-management-and-hunting`) |
| Food plots substitute for habitat | ⚠️ **Supplement and hunting tool, not substitute** (§24 → `agri-wildlife-management-and-hunting`) |
| Hang the deer in the shed to age it | ⚠️ **Above ~40°F that's spoilage** (§27 → `agri-wildlife-management-and-hunting`) |
| Trim the wound channel and lead is gone | ⚠️ **Fragments spread well beyond it** (§27 → `agri-wildlife-management-and-hunting`) |
| Freezing kills trichinella in wild game | ⚠️ **Not reliably. Cook thoroughly** (§27 → `agri-wildlife-management-and-hunting`) |
| Pasteurized milk is an H5N1 risk | ⚠️ **Pasteurization inactivates it; RAW milk is the risk** (§28.1) |
| RNA found in retail milk = infectious milk | ⚠️ **RNA detection ≠ viable virus** (§28.1) |
| A CWD test certifies meat as safe | ⚠️ **It is not a food safety test** (§28.2) |
| A healthy-looking deer can't have CWD | ⚠️ **12–24 months asymptomatic** (§28.2) |
