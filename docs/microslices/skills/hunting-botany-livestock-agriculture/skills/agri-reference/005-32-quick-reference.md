## §32. Quick Reference

### 32.1 Picker
| Question | Where |
|---|---|
| Plant looks bad — where do I start? | ⚠️ **pH, compaction, water — before fertilizer** (§4 → `agri-botany-and-plant-science`, §10 → `agri-soil-fertility-and-crop-production`) |
| Which leaves show the deficiency? | ⚠️ **Old = mobile nutrient; new = immobile** (§4 → `agri-botany-and-plant-science`) |
| Can I eat this plant? | ⚠️ **Not from a description. See §7 → `agri-botany-and-plant-science`** |
| Should I spray? | ⚠️ **Scout, identify, check the economic threshold** (§13 → `agri-soil-fertility-and-crop-production`) |
| Pest keeps coming back despite spraying | ⚠️ **Rotate MODE OF ACTION; check beneficials** (§13 → `agri-soil-fertility-and-crop-production`) |
| Soil feels hard, water pools | ⚠️ **Compaction. Dig a hole and look** (§10 → `agri-soil-fertility-and-crop-production`) |
| Cattle off feed after a ration change | ⚠️ **Acidosis. Transition gradually** (§17 → `agri-livestock-nutrition-health-and-welfare`) |
| Thin cows aren't breeding back | ⚠️ **Body condition drives reproduction** (§18 → `agri-livestock-nutrition-health-and-welfare`, §19 → `agri-livestock-nutrition-health-and-welfare`) |
| Dewormer stopped working | ⚠️ **Resistance. Targeted treatment + refugia** (§20 → `agri-livestock-nutrition-health-and-welfare`) |
| Pasture degrading | ⚠️ **Rest period, not stocking numbers alone** (§22 → `agri-livestock-nutrition-health-and-welfare`) |
| Too many deer, damaged habitat | ⚠️ **Antlerless harvest** (§24 → `agri-wildlife-management-and-hunting`) |
| Want better deer habitat | ⚠️ **Early succession: fire, timber work, edge** (§6 → `agri-botany-and-plant-science`, §24 → `agri-wildlife-management-and-hunting`) |
| Warm-weather harvest | ⚠️ **Quarter and ice fast; don't hang** (§27 → `agri-wildlife-management-and-hunting`) |
| Deer from a CWD area | ⚠️ **Test, bone out, label by animal, don't move carcass** (§28.2) |
| Dairy near poultry, H5N1 concern | ⚠️ **Biosecurity: equipment, people, traffic** (§20 → `agri-livestock-nutrition-health-and-welfare`, §28.1) |

### 32.2 ⚠️ Safety non-negotiables
- [ ] ⚠️ **Never eat a plant/fungus ID'd from text alone** (§7 → `agri-botany-and-plant-science`)
- [ ] ⚠️ **Four firearm rules, every time — especially "what's beyond"** (§25 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Positive target ID: the whole animal, identified** (§25 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Full-body harness from the ground up in a tree stand** (§25 → `agri-wildlife-management-and-hunting`)
- [ ] Current state regulations checked this season (§25 → `agri-wildlife-management-and-hunting`)
- [ ] Written landowner permission (§25 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Gloves when field dressing; don't handle sick animals** (§27 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Carcass cooled below 40°F fast** (§27 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Cook to safe internal temperature; bear/pig thoroughly** (§27 → `agri-wildlife-management-and-hunting`)
- [ ] ⚠️ **Quarantine incoming livestock 21–30 days** (§20 → `agri-livestock-nutrition-health-and-welfare`)
- [ ] Withdrawal times observed on any treated animal (§20 → `agri-livestock-nutrition-health-and-welfare`)
