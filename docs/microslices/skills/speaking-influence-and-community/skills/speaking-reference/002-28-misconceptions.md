## §28. Misconceptions

| Misconception | Correction |
|---|---|
| 93% of communication is nonverbal | ⚠️ **Two 1967 studies, n=30 and 37, on conflicting cues about FEELINGS** (§27.1) |
| Power posing raises your confidence hormonally | ⚠️ **The hormonal claim failed to replicate** (§27.1) |
| You can read deception from body language | ⚠️ **Weakly supported at best; clusters not single cues** (§27.1) |
| Speaking anxiety means you're not cut out for it | ⚠️ **It's an ordinary threat response. Exposure is the fix** (§2 → `speaking-what-the-field-knows-anxiety-audience-and-structure`) |
| The goal is to feel calm | ⚠️ **The goal is functioning while activated. Reappraise** (§2 → `speaking-what-the-field-knows-anxiety-audience-and-structure`) |
| The audience can see how nervous you are | ⚠️ **Far less than you feel it** (§2 → `speaking-what-the-field-knows-anxiety-audience-and-structure`) |
| Delivery is what makes a talk good | ⚠️ **Structure and substance dominate** (§4 → `speaking-what-the-field-knows-anxiety-audience-and-structure`, §18 → `speaking-persuasion-and-the-ethics-of-influence`) |
| Slides carry the talk | ⚠️ **Dense slides force a choice between reading and listening** (§8 → `speaking-language-delivery-visual-aids-and-practice`) |
| Bullet points are what slides are for | ⚠️ **They're your notes. Use a handout instead** (§8 → `speaking-language-delivery-visual-aids-and-practice`) |
| End with Q&A | ⚠️ **Close after it. The last words should be yours** (§5 → `speaking-what-the-field-knows-anxiety-audience-and-structure`, §9 → `speaking-language-delivery-visual-aids-and-practice`) |
| "I don't know" damages credibility | ⚠️ **Bluffing does. Not knowing doesn't** (§9 → `speaking-language-delivery-visual-aids-and-practice`) |
| Filler words are a serious problem | ⚠️ **Far less noticeable to audiences than to you** (§7 → `speaking-language-delivery-visual-aids-and-practice`) |
| Mirroring builds rapport | ⚠️ **The deliberate version is detectable and costs trust** (§13 → `speaking-listening-rapport-difficult-conversations-and-negotiation`) |
| Listening means waiting politely | ⚠️ **It's the mechanism of durable persuasion** (§12 → `speaking-listening-rapport-difficult-conversations-and-negotiation`, §18 → `speaking-persuasion-and-the-ethics-of-influence`) |
| Someone describing a problem wants a solution | ⚠️ **Usually not. Ask which they want** (§12 → `speaking-listening-rapport-difficult-conversations-and-negotiation`) |
| Intent is what matters | ⚠️ **You can't know theirs. Speak to impact** (§14 → `speaking-listening-rapport-difficult-conversations-and-negotiation`) |
| The feedback sandwich softens criticism | ⚠️ **It gets learned and discounted. Be direct and kind** (§16 → `speaking-listening-rapport-difficult-conversations-and-negotiation`) |
| Conflict means something is wrong | ⚠️ **No visible conflict usually means it's suppressed** (§17 → `speaking-listening-rapport-difficult-conversations-and-negotiation`) |
| Facts change minds | ⚠️ **Facts help; identity-linked beliefs resist them** (§18 → `speaking-persuasion-and-the-ethics-of-influence`) |
| Microtargeting is enormously effective | ⚠️ **Evidence conflicts; measured effects are small** (§27.2) |
| Persuasion and manipulation differ by degree | ⚠️ **Structurally different. Apply the disclosure test** (§19 → `speaking-persuasion-and-the-ethics-of-influence`) |
| A structureless group has no power structure | ⚠️ **It has an invisible, unaccountable one** (§20 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| The platform makes the community | ⚠️ **Purpose, people and rhythm do** (§21 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| A code of conduct signals safety | ⚠️ **Only if enforced. Unenforced is worse than none** (§21 → `speaking-groups-community-facilitation-organizing-and-conflict`, §25 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| Volunteers are unpaid staff | ⚠️ **Paid in meaning, belonging and being asked** (§24 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| Burnout is a personal resilience issue | ⚠️ **Usually structural. Self-care advice can dodge the fix** (§24 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| Working around a harmful person keeps the peace | ⚠️ **The missing stair. It sacrifices everyone unwarned** (§25 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| Autistic people have a communication deficit | ⚠️ **Double empathy: the difficulty is mutual** (§26 → `speaking-groups-community-facilitation-organizing-and-conflict`) |
| Winning the argument changes behaviour | ⚠️ **Attitude and behaviour effects may not correlate** (§27.2) |
