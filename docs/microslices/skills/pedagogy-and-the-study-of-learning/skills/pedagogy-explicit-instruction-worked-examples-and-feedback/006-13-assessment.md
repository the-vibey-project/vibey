## §13. Assessment

**⚠️ Formative (for learning) vs summative (of learning) — ⚠️ and the same instrument can
serve either purpose depending on what happens next.**
**⚠️ Validity is a property of the INFERENCE, not the test** — ⚠️ **"is this test valid?"
is malformed; "is this inference from this score, for this purpose, valid?" is the
question.** **Reliability, and ⚠️ the fact that reliability constrains validity.**
**⚠️ Assessment drives learning through backwash** — ⚠️ **students study what is assessed,
so the assessment IS the operative curriculum** whatever the syllabus says.
**⚠️ Practical cautions**: ⚠️ **multiple choice can test deeply if distractors are
misconception-based; comparative judgement is a genuinely useful technique for
hard-to-mark work; and ⚠️ standard-setting is a judgement, not a measurement — "proficient"
is a decision** (§25.2 → `pedagogy-reference`).
