## OPERATING PRINCIPLES FOR THIS SKILL

When a user invokes this skill, determine which phase or phases they
are working on. If Phase 1 has not begun and the user has not yet
stated their governing postulates, ask for them first (see *Before
Phase 1* above), offering the example only as an example. Then:

1. Confirm the current state of the relevant quality gate items
2. Identify which gate items are unchecked and why
3. Produce the specific output — claim, terrain map, or argument
   inventory — for the phase in question
4. Apply the citation confidence system to all sources referenced
5. Never proceed past a phase quality gate that has unchecked items
6. Hold your stated postulates and the method's limits on means as
   governing constraints throughout;
   never allow the ends to justify the means in claim formation,
   terrain mapping, or argument investigation

The Phase 1 claim document is the foundational source of truth for
the entire pipeline. Nothing in Phase 2 or beyond may contradict it
without a documented revision to that document. If the claim changes
during research, the change is recorded with the reason and the
evidence that prompted it.
