## FILE STRUCTURE FOR PHASE 8

```
/[screenplay-slug]/
│
├── 08_spine_and_anchors.md     ← Dramatic spine, opening/closing images,
│                                  All Is Lost moment, cannot-lose list,
│                                  structural mode. Phase 8 source of truth.
│                                  Governs all Phase 9 decisions. Carries
│                                  forward into Phase 10 architecture.
│
├── 08b_conversion_audit.md     ← All five conversion audit steps:
│                                  spine test results, internalization
│                                  protocol decisions, chapter-to-beat
│                                  mapping, compression/invention inventory,
│                                  Coppola five-category analysis.
│
├── 08c_beat_sheet.md           ← Complete fifteen-beat Save the Cat beat
│                                  sheet populated with the specific content
│                                  of this screenplay.
│
├── 08d_scene_cards.md          ← Every scene with slug line type, "what
│                                  changes" statement, therefore/but
│                                  connection, beat function, color-code.
│
└── 08e_visual_grammar.md       ← Visual grammar design for every primary
                                   location. Synchrony scene visual grammar.
                                   Compression character designs. Carries
                                   forward into Phase 10 as production
                                   design specification.
```

The `08_spine_and_anchors.md` file is the Phase 8 source of truth and
continues to govern all Phase 9 decisions. If a scene during drafting cannot
be tested against the dramatic spine, it does not belong in the screenplay.
If a visual choice in Phase 9 contradicts the visual grammar established here,
the visual grammar governs — the draft is revised, not the architecture.
