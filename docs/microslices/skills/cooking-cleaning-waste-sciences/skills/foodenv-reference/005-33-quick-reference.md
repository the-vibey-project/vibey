## §33. Quick Reference

### 33.1 Picker
| Question | Where |
|---|---|
| Meat came out tough | ⚠️ **Wrong cut/method pairing — collagen needs time** (§3 → `foodenv-food-science`) |
| Food won't brown | ⚠️ **Wet surface or crowded pan** (§2 → `foodenv-food-science`, §4 → `foodenv-food-science`) |
| Sauce broke | ⚠️ **Re-emulsify slowly into a fresh base** (§6 → `foodenv-food-science`) |
| Dish tastes flat | ⚠️ **Salt, then acid** (§9 → `foodenv-food-science`) |
| Is this leftover safe? | ⚠️ **Time in the danger zone, not smell** (§12 → `foodenv-food-safety-and-food-service`) |
| Big pot of hot stew to store | ⚠️ **Shallow pans / ice bath. Don't fridge it whole** (§12 → `foodenv-food-safety-and-food-service`) |
| Grease won't shift | ⚠️ **Alkaline cleaner, not vinegar** (§20 → `foodenv-cleaning-chemistry`) |
| Limescale won't shift | ⚠️ **Acid, not bleach** (§20 → `foodenv-cleaning-chemistry`) |
| Blood/egg/milk stain | ⚠️ **COLD water + enzyme** (§20 → `foodenv-cleaning-chemistry`, §23 → `foodenv-cleaning-chemistry`) |
| Disinfectant not working | ⚠️ **Clean first; respect dwell time** (§22 → `foodenv-cleaning-chemistry`) |
| Can I mix these two cleaners? | ⚠️ **No** (§22 → `foodenv-cleaning-chemistry`) |
| Is this recyclable? | ⚠️ **Check your municipality. When in doubt, bin it** (§27 → `foodenv-wastewater-and-waste-management`) |
| Compostable packaging, no program | ⚠️ **Landfill. It won't compost there** (§26 → `foodenv-wastewater-and-waste-management`, §28 → `foodenv-wastewater-and-waste-management`) |
| Most impactful waste change? | ⚠️ **Reduce food waste; reduce and reuse before recycling** (§25 → `foodenv-wastewater-and-waste-management`) |

### 33.2 ⚠️ Non-negotiables
- [ ] ⚠️ **Never mix bleach with ammonia or acid** (§22 → `foodenv-cleaning-chemistry`)
- [ ] ⚠️ **Cook to temperature; use a thermometer, not colour** (§12 → `foodenv-food-safety-and-food-service`)
- [ ] ⚠️ **Cool 135→70→41°F on the clock** (§12 → `foodenv-food-safety-and-food-service`)
- [ ] ⚠️ **2-hour danger zone limit** (§12 → `foodenv-food-safety-and-food-service`)
- [ ] Raw below ready-to-eat in the fridge (§14 → `foodenv-food-safety-and-food-service`)
- [ ] ⚠️ **Handwash 20s; gloves aren't a substitute** (§14 → `foodenv-food-safety-and-food-service`)
- [ ] ⚠️ **Tested procedures for home canning — botulism** (§10 → `foodenv-food-science`)
- [ ] ⚠️ **Clean before disinfecting; honour dwell time** (§22 → `foodenv-cleaning-chemistry`)
- [ ] ⚠️ **Lithium batteries never in the recycling or trash bin — fire** (§27 → `foodenv-wastewater-and-waste-management`)
- [ ] Only urine, faeces, toilet paper down the toilet (§24 → `foodenv-wastewater-and-waste-management`)
