## §27. Misconceptions

| Misconception | Correction |
|---|---|
| Arrow's theorem proves voting is pointless | ⚠️ **It proves no rule satisfies all those axioms. It's about trade-offs** (§7 → `polisci-collective-action-commons-social-choice-and-voting`) |
| "The will of the majority" always exists | ⚠️ **Condorcet cycles mean it may not** (§7 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Some voting system is neutral | ⚠️ **Every rule embeds a theory of representation** (§8 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Strategic voting could be designed away | ⚠️ **Gibbard-Satterthwaite says no** (§7 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Ranked choice is monotonic | ⚠️ **IRV can fail monotonicity** (§8 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Duverger's Law is a law | ⚠️ **A strong tendency. India and Canada qualify it** (§8 → `polisci-collective-action-commons-social-choice-and-voting`) |
| The commons is inevitably a tragedy | ⚠️ **Ostrom documented durable self-governed commons** (§6 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Hardin described a managed commons | ⚠️ **He described OPEN ACCESS. Different thing** (§6 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Democracy means majority rule | ⚠️ **Liberal democracy also constrains majorities** (§9 → `polisci-constitutional-design-electoral-systems-and-institutions`, §13 → `polisci-constitutional-design-electoral-systems-and-institutions`) |
| Presidentialism is proven unstable | ⚠️ **Linz is influential and contested** (§11 → `polisci-constitutional-design-electoral-systems-and-institutions`) |
| Big diffuse majorities win in democracies | ⚠️ **Olson: concentrated interests organize better** (§5 → `polisci-collective-action-commons-social-choice-and-voting`) |
| Campaigns swing elections | ⚠️ **Field experiments find persuasion effects small** (§16 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Voters reward good policy | ⚠️ **They also punish droughts and shark attacks** (§16 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Economic voting is objective | ⚠️ **Partisans disagree about economic facts** (§16 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| The margin of error covers polling uncertainty | ⚠️ **Sampling only. Real uncertainty is wider** (§17 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| A 30% forecast that happens was wrong | ⚠️ **That's not how probabilities work** (§17 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Americans have become ideologically extreme | ⚠️ **Affective polarization is better evidenced than ideological** (§18 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Social media clearly caused polarization | ⚠️ **Large studies find mixed and smaller effects** (§18 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Implementation follows from legislation | ⚠️ **Street-level discretion makes policy** (§14 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`, §24 → `polisci-regimes-state-capacity-corruption-ir-and-field-problems`) |
| Targets improve public services | ⚠️ **Goodhart's Law. Often gamed** (§14 → `polisci-bureaucracy-parties-voter-behaviour-and-polarization`) |
| Corruption indices measure corruption | ⚠️ **Mostly they measure PERCEPTIONS** (§21 → `polisci-regimes-state-capacity-corruption-ir-and-field-problems`) |
| Wealth causes democratization | ⚠️ **Przeworski: it better predicts SURVIVAL** (§19 → `polisci-regimes-state-capacity-corruption-ir-and-field-problems`) |
| War happens when bargaining fails irrationally | ⚠️ **Information, commitment, indivisibility** (§23 → `polisci-regimes-state-capacity-corruption-ir-and-field-problems`) |
| Peacekeeping doesn't work | ⚠️ **Evidence is more favourable than the reputation** (§23 → `polisci-regimes-state-capacity-corruption-ir-and-field-problems`) |
| Democracy indices are objective measurement | ⚠️ **Mostly expert judgement, and that's disputed** (§26.2) |
| The backsliding critique proves decline is fake | ⚠️ **Its own authors decline to claim that** (§26.2) |
| All democracy indices agree | ⚠️ **V-Dem and BTI report different pictures** (§26.1) |
