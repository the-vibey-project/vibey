## Blake Snyder's Save the Cat: 15 beats

Save the Cat (2005) is a high-resolution realization of Vogler for screenwriters. The second act is broken into "islands" precisely because the monomyth's Initiation phase is where structural collapse most often occurs.

| Beat | Page target | Campbell equivalent |
|------|-------------|---------------------|
| Opening Image | 1 | Ordinary World established visually |
| Theme Stated | 5 | The lesson the Hero will learn, stated indirectly |
| Setup | 1-10 | Ordinary World + flaws + need established |
| Catalyst | 12 | Call to Adventure |
| Debate | 12-25 | Refusal of the Call |
| Break into Two | 25 | Crossing the First Threshold |
| B Story | 30 | Mentor/Ally relationship introduced |
| Fun and Games | 30-55 | Tests, Allies, Enemies (the "promise of the premise") |
| Midpoint | 55 | False victory or false defeat |
| Bad Guys Close In | 55-75 | Approach to the Inmost Cave |
| All Is Lost | 75 | Ordeal — the false death |
| Dark Night of the Soul | 75-85 | The Abyss — "Why have I failed?" |
| Break into Three | 85 | Road Back — the solution found |
| Finale | 85-110 | Resurrection — hero applies what they learned |
| Final Image | 110 | Return with Elixir — mirror/inversion of Opening Image |

**Snyder's contribution**: granular pacing, particularly the segmentation of the second act. Identifies the Midpoint reversal (false victory or false defeat at page 55) as the crucial second-act hinge that prevents sagging.
