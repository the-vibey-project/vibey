## Quick reference: framework selection guide

| Situation | Best framework |
|-----------|---------------|
| Fiction outline, first draft | Vogler 12 stages as diagnostic |
| Screenplay structure and pacing | Save the Cat beats |
| Fiction revision (is tension rising?) | Fichtean Curve + Freytag Pyramid |
| Understanding villain depth | Jungian Shadow + Campbell |
| Stories of organizational transformation | Murdock's Heroine's Journey |
| Marketing copy, B2B content | StoryBrand (reader = Hero, brand = Mentor) |
| White paper narrative arc | Reader's journey from problem to transformed understanding |
| Pitch deck structure | Problem → Why now → Ordeal (why existing approaches fail) → Elixir |
| Thought leadership piece | Author's journey instrumental to reader's; transfer Hero role explicitly |
| Detailed analysis of folk/fairy tale | Propp's 31 functions |
| Academic critique of the monomyth | Dundes, Toelken, structural folklorists |
