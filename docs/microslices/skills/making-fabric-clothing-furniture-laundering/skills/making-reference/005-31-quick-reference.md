## §31. Quick Reference

### 31.1 Picker
| Problem | Where |
|---|---|
| Garment twists on the body | ⚠️ **Cut off-grain. Not fixable** (§8 → `making-garment-drafting-seams-and-construction`) |
| Hem is uneven after wearing | ⚠️ **Bias grew. Hang before hemming** (§8 → `making-garment-drafting-seams-and-construction`) |
| Garment shrank in the first wash | ⚠️ **Didn't preshrink the fabric** (§10 → `making-garment-drafting-seams-and-construction`) |
| Seams snap on a knit garment | ⚠️ **Lockstitch on stretch fabric** (§11 → `making-garment-drafting-seams-and-construction`) |
| Holes appear along knit seams later | ⚠️ **Sharp needle cut the loops** (§14 → `making-garment-drafting-seams-and-construction`) |
| Puckered seams | ⚠️ **Needle, then tension, then rethread** (§11 → `making-garment-drafting-seams-and-construction`, §14 → `making-garment-drafting-seams-and-construction`) |
| Looks homemade | ⚠️ **Press at every stage** (§12 → `making-garment-drafting-seams-and-construction`) |
| Tabletop split | ⚠️ **Fixed cross-grain. Wood moves** (§16 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Joint failed | ⚠️ **End grain, or the wrong joint for the force** (§17 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Chair wobbles | ⚠️ **Loose joint. Clean out old glue before regluing** (§21 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Towels stopped absorbing | ⚠️ **Fabric softener buildup** (§22 → `making-laundering-stain-removal-care-and-mending`) |
| Activewear smells after washing | ⚠️ **Oleophilic polyester; lipase, no softener** (§23 → `making-laundering-stain-removal-care-and-mending`) |
| Sweater felted | ⚠️ **Heat + moisture + agitation. Irreversible** (§23 → `making-laundering-stain-removal-care-and-mending`) |
| Stain set permanently | ⚠️ **Heat, or the dryer** (§24 → `making-laundering-stain-removal-care-and-mending`) |
| Stain came back | ⚠️ **Residual sugar/tannin or detergent. Rinse more** (§24 → `making-laundering-stain-removal-care-and-mending`) |
| Holes in wool storage | ⚠️ **Moths. Clean before storing; freeze** (§26 → `making-laundering-stain-removal-care-and-mending`) |
| Reducing microplastic from laundry | ⚠️ **Fabric choice first, then cold and gentle** (§27.1) |

### 31.2 Before you cut / before you wash
**Cutting:**
- [ ] ⚠️ **Fabric preshrunk the way the garment will be washed** (§10 → `making-garment-drafting-seams-and-construction`)
- [ ] ⚠️ **Grain straightened and pieces aligned to it** (§8 → `making-garment-drafting-seams-and-construction`)
- [ ] Nap direction consistent; pattern match planned (§10 → `making-garment-drafting-seams-and-construction`)
- [ ] Toile made for anything fitted or expensive (§13 → `making-garment-drafting-seams-and-construction`)

**Washing:**
- [ ] ⚠️ **Care label read; strictest component governs** (§1 → `making-fibres-yarn-weaving-knitting-and-dyeing`, §23 → `making-laundering-stain-removal-care-and-mending`)
- [ ] ⚠️ **Stains treated COLD before the wash** (§24 → `making-laundering-stain-removal-care-and-mending`)
- [ ] Machine not overloaded (§22 → `making-laundering-stain-removal-care-and-mending`)
- [ ] ⚠️ **Nothing stained going into the dryer** (§24 → `making-laundering-stain-removal-care-and-mending`)
- [ ] ⚠️ **Clean before storing** (§25 → `making-laundering-stain-removal-care-and-mending`, §26 → `making-laundering-stain-removal-care-and-mending`)
