## §28. Misconceptions

| Misconception | Correction |
|---|---|
| All fibres weaken when wet | ⚠️ **Cotton and linen get STRONGER; rayon much weaker** (§1 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Rayon is a natural fibre | ⚠️ **Regenerated cellulose, and fragile wet** (§1 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| A blend averages its components' care | ⚠️ **Inherits the strictest requirement** (§1 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Higher yarn number = heavier | ⚠️ **Inverted in cotton/worsted count; not in denier/tex** (§2 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Satin is a fibre | ⚠️ **A weave. Long floats — lustrous and snag-prone** (§3 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Jersey curling is a defect | ⚠️ **Structural. Stitch asymmetry** (§4 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Any dye works on any fibre | ⚠️ **Dye classes are fibre-specific; polyester needs ~130°C** (§6 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Strong fibres resist pilling | ⚠️ **They pill WORSE — the pill can't break off** (§7 → `making-fibres-yarn-weaving-knitting-and-dyeing`) |
| Follow the print, not the grain | ⚠️ **Follow the GRAIN. Off-grain garments twist** (§8 → `making-garment-drafting-seams-and-construction`) |
| Hem a bias garment immediately | ⚠️ **Hang it 24 hours first — bias grows** (§8 → `making-garment-drafting-seams-and-construction`) |
| Knits need the usual ease | ⚠️ **Often zero or negative** (§9 → `making-garment-drafting-seams-and-construction`) |
| Wash the garment, not the fabric | ⚠️ **Preshrink BEFORE cutting** (§10 → `making-garment-drafting-seams-and-construction`) |
| A lockstitch is fine on knits | ⚠️ **It snaps. Use stretch stitch or serger** (§11 → `making-garment-drafting-seams-and-construction`) |
| Ironing and pressing are the same | ⚠️ **Press: lift and lower. Sliding distorts** (§12 → `making-garment-drafting-seams-and-construction`) |
| Diagonal wrinkles mean bad sewing | ⚠️ **They point toward where it's too tight** (§13 → `making-garment-drafting-seams-and-construction`) |
| A needle is a needle | ⚠️ **A sharp needle CUTS knit loops. Use ballpoint** (§14 → `making-garment-drafting-seams-and-construction`) |
| Tension problem = adjust tension | ⚠️ **Rethread first, presser foot up** (§14 → `making-garment-drafting-seams-and-construction`) |
| Kiln-dried wood is stable | ⚠️ **It moves with humidity forever** (§16 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Screw the tabletop down firmly | ⚠️ **It will split. Use fasteners that let it slide** (§16 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Glue is glue; end grain is fine | ⚠️ **End grain glues poorly. Joints create long grain** (§17 → `making-woodworking-joinery-finishing-and-upholstery`, §18 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Squeeze-out means good clamping | ⚠️ **Even pressure is the goal, not squeeze-out** (§18 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Oily rags are just messy | ⚠️ **They spontaneously combust. Spread flat or submerge** (§19 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Foam density means firmness | ⚠️ **Density predicts longevity; firmness is feel** (§20 → `making-woodworking-joinery-finishing-and-upholstery`) |
| A wobbly chair has a short leg | ⚠️ **Usually a loose joint** (§21 → `making-woodworking-joinery-finishing-and-upholstery`) |
| Cold water doesn't clean | ⚠️ **Sinner's circle — substitute chemistry and time** (§22 → `making-laundering-stain-removal-care-and-mending`) |
| Fabric softener is good for laundry | ⚠️ **Ruins towels, activewear and FR sleepwear** (§22 → `making-laundering-stain-removal-care-and-mending`) |
| More detergent cleans better | ⚠️ **Residue attracts soil. Overloading is the real issue** (§22 → `making-laundering-stain-removal-care-and-mending`) |
| Optical brighteners clean | ⚠️ **They're fluorescent dye. They build up** (§22 → `making-laundering-stain-removal-care-and-mending`) |
| Hang wet wool to dry | ⚠️ **It stretches permanently. Dry flat** (§23 → `making-laundering-stain-removal-care-and-mending`) |
| Hot water on any stain | ⚠️ **Heat SETS protein stains permanently** (§24 → `making-laundering-stain-removal-care-and-mending`) |
| Rub the stain out | ⚠️ **Blot. Rubbing drives it in and abrades** (§24 → `making-laundering-stain-removal-care-and-mending`) |
| Bleach fixes rust stains | ⚠️ **Chlorine makes rust WORSE. Use acid/oxalic** (§24 → `making-laundering-stain-removal-care-and-mending`) |
| Plastic boxes protect stored textiles | ⚠️ **Traps moisture, yellows. Use breathable cotton** (§25 → `making-laundering-stain-removal-care-and-mending`) |
| Cedar blocks kill moths | ⚠️ **Repellent at best. Cleaning and freezing work** (§26 → `making-laundering-stain-removal-care-and-mending`) |
| Moths eat clothes generally | ⚠️ **Keratin only — wool, silk, fur. And soil attracts them** (§26 → `making-laundering-stain-removal-care-and-mending`) |
| PFAS-free means the same performance | ⚠️ **Repels water well, oil poorly** (§27.2) |
| One number describes microfibre shedding | ⚠️ **Sources vary by 100×; no standard method yet** (§27.1) |
