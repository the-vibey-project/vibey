## §25. Misconceptions

| Misconception | Correction |
|---|---|
| Your attachment style explains your relationships | ⚠️ **Extrapolated well past the infant evidence** (§2 → `family-reading-claims-attachment-and-couple-relationships`) |
| Gottman predicts divorce with 94% accuracy | ⚠️ **Methodologically criticized; not out-of-sample** (§3 → `family-reading-claims-attachment-and-couple-relationships`) |
| Happy couples don't fight | ⚠️ **Most conflicts are perpetual; repair is the variable** (§4 → `family-reading-claims-attachment-and-couple-relationships`) |
| Opposites attract / similarity predicts success | ⚠️ **Both weakly supported** (§3 → `family-reading-claims-attachment-and-couple-relationships`) |
| Staying together is always better for the kids | ⚠️ **High conflict is not protective** (§5 → `family-reading-claims-attachment-and-couple-relationships`, §13 → `family-behaviour-genetics-structure-and-caregiving`) |
| Fix the problem child | ⚠️ **Symptoms are often system properties** (§6 → `family-systems-child-development-and-parenting`) |
| The first three years determine everything | ⚠️ **Oversells sensitive periods; plasticity continues** (§8 → `family-systems-child-development-and-parenting`) |
| The 30-million-word gap | ⚠️ **The figure failed replication** (§8 → `family-systems-child-development-and-parenting`) |
| Parenting style is the main driver of outcomes | ⚠️ **Genetic confounding is substantial** (§9 → `family-systems-child-development-and-parenting`, §10 → `family-behaviour-genetics-structure-and-caregiving`) |
| Behaviour genetics means parents don't matter | ⚠️ **Abuse and neglect have large effects; range matters** (§10 → `family-behaviour-genetics-structure-and-caregiving`) |
| Heritability means fixed | ⚠️ **Population statistic in an environment** (§10 → `family-behaviour-genetics-structure-and-caregiving`) |
| Harsh punishment teaches discipline | ⚠️ **Consistency beats severity; no benefit found** (§11 → `family-behaviour-genetics-structure-and-caregiving`) |
| Birth order shapes personality | ⚠️ **Essentially a myth; within-family studies dissolve it** (§12 → `family-behaviour-genetics-structure-and-caregiving`) |
| Your ACE score predicts your future | ⚠️ **Population tool, poor individual prediction** (§14 → `family-behaviour-genetics-structure-and-caregiving`) |
| Resilience is exceptional | ⚠️ **It's the ordinary outcome** (§14 → `family-behaviour-genetics-structure-and-caregiving`) |
| Community is inherently good | ⚠️ **Bonding capital has a dark side** (§16 → `family-social-capital-community-and-program-evaluation`) |
| More cohesion means safer neighbourhoods | ⚠️ **Need willingness to ACT, not just trust** (§22 → `family-social-capital-community-and-program-evaluation`) |
| Loneliness is an elderly problem | ⚠️ **Young adults report it at least as much** (§18 → `family-social-capital-community-and-program-evaluation`, §24.1) |
| Loneliness and isolation are the same | ⚠️ **Subjective vs objective; different remedies** (§18 → `family-social-capital-community-and-program-evaluation`) |
| We know how to fix loneliness | ⚠️ **Effective interventions "yet to be identified"** (§24.1) |
| Just try harder to make friends | ⚠️ **Proximity and repetition, not effort** (§17 → `family-social-capital-community-and-program-evaluation`) |
| Awareness campaigns build community | ⚠️ **Structural changes outperform them** (§19 → `family-social-capital-community-and-program-evaluation`, §24.1) |
| A pre-post improvement shows the program worked | ⚠️ **Regression to the mean; need a control** (§23 → `family-social-capital-community-and-program-evaluation`) |
| Plausible programs are at worst harmless | ⚠️ **Scared Straight increased offending** (§23 → `family-social-capital-community-and-program-evaluation`) |
| Social decline is uniform | ⚠️ **It's concentrated by class** (§24.2) |
