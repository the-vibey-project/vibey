## §3. Value

> **⚠️ Value does more work than colour, and this is the single most useful technical fact
> in visual art.** ⚠️ **Convert any effective image to greyscale and it still reads;
> convert an ineffective one and it collapses into mush.** **Composition, depth, focus and
> legibility are carried primarily by value structure.**

**⚠️ Why, mechanistically**: **the human visual system processes luminance at much higher
spatial resolution than chrominance** — **which is exactly why image and video compression
throws away colour detail first and nobody notices** (see a graphics reference on chroma
subsampling).
**Practical consequences:**
- **⚠️ Squint at the work.** **Squinting suppresses detail and colour and shows you the
  value masses. If it doesn't read squinted, it doesn't read.**
- **⚠️ Notan / big-shape thinking**: **design in three or four value masses before any
  detail.**
- **⚠️ Value CONTRAST directs the eye.** **The greatest light-dark contrast is where the
  viewer looks first — so put it where you want them.**
- **⚠️ Value controls depth**: **atmospheric perspective compresses value range with
  distance** (§6).
- ⚠️ **A common failure is correct local values with no overall structure** — **every
  object rendered accurately, the whole picture reading as noise.**
