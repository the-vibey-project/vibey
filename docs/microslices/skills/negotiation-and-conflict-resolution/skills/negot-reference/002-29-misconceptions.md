## §29. Misconceptions

| Misconception | Correction |
|---|---|
| Good negotiators are good talkers | ⚠️ **Preparation and alternatives dominate technique** (§1 → `negot-framings-batna-zopa-interests-and-preparation`, §5 → `negot-framings-batna-zopa-interests-and-preparation`) |
| The pie is fixed | ⚠️ **Fixed-pie bias — parties miss issues they AGREE on** (§2 → `negot-framings-batna-zopa-interests-and-preparation`) |
| Leverage comes from confidence | ⚠️ **It comes from your BATNA** (§3 → `negot-framings-batna-zopa-interests-and-preparation`) |
| A good deal beats their offer | ⚠️ **A good deal beats your BATNA** (§3 → `negot-framings-batna-zopa-interests-and-preparation`) |
| Meet in the middle is fair | ⚠️ **It rewards whoever anchored more extremely** (§6 → `negot-anchoring-concessions-value-creation-and-closing`, §13 → `negot-biases-emotion-fairness-and-trust`) |
| Always make the first offer | ⚠️ **Conditional — see complexity and information** (§6 → `negot-anchoring-concessions-value-creation-and-closing`, §28.2) |
| Anchor as extremely as possible | ⚠️ **Raises impasse and anger; justify it instead** (§6 → `negot-anchoring-concessions-value-creation-and-closing`, §28.2) |
| Never reveal information | ⚠️ **Share priorities, not reservation values** (§9 → `negot-anchoring-concessions-value-creation-and-closing`) |
| Concede to build goodwill | ⚠️ **Unreciprocated concessions train more demands** (§7 → `negot-anchoring-concessions-value-creation-and-closing`, §13 → `negot-biases-emotion-fairness-and-trust`) |
| Emotions have no place | ⚠️ **They're information. Anxiety costs more than anger** (§12 → `negot-biases-emotion-fairness-and-trust`) |
| Anger is an effective tactic | ⚠️ **It borrows from the relationship's future** (§12 → `negot-biases-emotion-fairness-and-trust`, §14 → `negot-biases-emotion-fairness-and-trust`) |
| Both sides can't be sincere | ⚠️ **Self-serving fairness bias is a real perceptual distortion** (§11 → `negot-biases-emotion-fairness-and-trust`) |
| They rejected it because of the terms | ⚠️ **Reactive devaluation — same offer, different source** (§11 → `negot-biases-emotion-fairness-and-trust`) |
| People maximize money | ⚠️ **They reject profitable unfair deals** (§13 → `negot-biases-emotion-fairness-and-trust`) |
| Process doesn't matter if the outcome is right | ⚠️ **Procedural fairness independently drives acceptance** (§13 → `negot-biases-emotion-fairness-and-trust`) |
| Verification signals distrust | ⚠️ **It's compatible with trust. Objecting to it is a tactic** (§14 → `negot-biases-emotion-fairness-and-trust`) |
| Toughness resists pressure | ⚠️ **Having somewhere else to go resists pressure** (§15 → `negot-hard-tactics-multiparty-culture-power-and-remote`) |
| Interest-based negotiation always wins | ⚠️ **Assumes good faith and a non-distributive structure** (§4 → `negot-framings-batna-zopa-interests-and-preparation`) |
| Culture tells you how they'll behave | ⚠️ **Distributions, not individuals. Hypotheses, not conclusions** (§18 → `negot-hard-tactics-multiparty-culture-power-and-remote`) |
| Technique offsets power imbalance | ⚠️ **It doesn't. That's what structural remedies are for** (§19 → `negot-hard-tactics-multiparty-culture-power-and-remote`) |
| Sort out conflict over email | ⚠️ **Reliably bad. Voice for conflict, writing for detail** (§20 → `negot-hard-tactics-multiparty-culture-power-and-remote`) |
| Conflict is inherently bad | ⚠️ **Task conflict helps; relationship conflict harms** (§21 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| Any conflict can be mediated | ⚠️ **Escalation stage determines what intervention works** (§21 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| A mediator decides | ⚠️ **No decision authority. That's the defining feature** (§22 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| Arbitration is cheap and quick | ⚠️ **Often, and costs have risen; appeal is very limited** (§23 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| Our case is strong so we should litigate | ⚠️ **Both sides think that. Most settle anyway** (§11 → `negot-biases-emotion-fairness-and-trust`, §23 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| Settlement resolves the conflict | ⚠️ **Settlement, resolution and reconciliation differ** (§26 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| Anything not illegal is fair game | ⚠️ **Ask whether it would still work if they knew** (§27 → `negot-conflict-analysis-mediation-adr-workplace-and-ethics`) |
| AI can negotiate for you now | ⚠️ **Better at preparation than at claiming value** (§28.1) |
