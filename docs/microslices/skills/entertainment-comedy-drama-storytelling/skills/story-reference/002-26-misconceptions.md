## §26. Misconceptions

| Misconception | Correction |
|---|---|
| Structure models tell you how to write | ⚠️ **They're retrofitted descriptions. Use for diagnosis** (§1 → `story-rules-character-structure-and-scene`, §4 → `story-rules-character-structure-and-scene`) |
| The hero's journey is universal | ⚠️ **Campbell was doing comparative mythology, fitted loosely** (§4 → `story-rules-character-structure-and-scene`) |
| All drama is conflict | ⚠️ **Kishōtenketsu disproves it** (§4 → `story-rules-character-structure-and-scene`) |
| Three-act structure is a rule | ⚠️ **So general it's nearly unfalsifiable** (§4 → `story-rules-character-structure-and-scene`) |
| Story problems are structure problems | ⚠️ **Usually scene problems — nobody wants anything** (§5 → `story-rules-character-structure-and-scene`) |
| Bigger stakes mean more tension | ⚠️ **Specific and personal beats large** (§6 → `story-rules-character-structure-and-scene`) |
| Surprise creates tension | ⚠️ **Dramatic irony does. The bomb under the table** (§6 → `story-rules-character-structure-and-scene`) |
| Good dialogue sounds like real speech | ⚠️ **Real speech is unusable. It's compressed** (§7 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| Characters should say what they feel | ⚠️ **That's "on the nose." Subtext** (§7 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| The audience needs the backstory up front | ⚠️ **Withhold. Late as possible** (§10 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| Protagonists must be likeable | ⚠️ **They must be interesting and want something** (§3 → `story-rules-character-structure-and-scene`) |
| Every protagonist needs a change arc | ⚠️ **Flat arcs transform the world instead** (§3 → `story-rules-character-structure-and-scene`) |
| Comedy can't be taught | ⚠️ **It's the most empirically iterated craft there is** (§12 → `story-comedy-jokes-improv-standup-and-timing`, §17 → `story-comedy-jokes-improv-standup-and-timing`) |
| Random is funny | ⚠️ **No pattern to violate. Comedy needs internal logic** (§14 → `story-comedy-jokes-improv-standup-and-timing`) |
| Just be funny in the scene | ⚠️ **Find the game and play it** (§14 → `story-comedy-jokes-improv-standup-and-timing`, §16 → `story-comedy-jokes-improv-standup-and-timing`) |
| "Yes, and" means agree with everything | ⚠️ **Accept the established reality, then add** (§16 → `story-comedy-jokes-improv-standup-and-timing`) |
| Timing is innate | ⚠️ **It's rhythm, and it's learnable — and made in the edit** (§18 → `story-comedy-jokes-improv-standup-and-timing`, §23 → `story-acting-directing-medium-and-industry`) |
| The K sound is funnier | ⚠️ **Weakly evidenced folklore; rhythm is the real effect** (§13 → `story-comedy-jokes-improv-standup-and-timing`) |
| Method acting means staying in character | ⚠️ **A distortion of the technique** (§20 → `story-acting-directing-medium-and-industry`) |
| Direct actors by describing the emotion | ⚠️ **Give an action, not a result** (§20 → `story-acting-directing-medium-and-industry`, §21 → `story-acting-directing-medium-and-industry`) |
| Audiences forgive bad sound like bad picture | ⚠️ **They don't. Sound is half of picture** (§23 → `story-acting-directing-medium-and-industry`) |
| Notes from executives are wrong | ⚠️ **Usually the right problem, wrong solution** (§24 → `story-acting-directing-medium-and-industry`) |
| Someone knows what will succeed | ⚠️ **"Nobody knows anything." Power-law outcomes** (§24 → `story-acting-directing-medium-and-industry`) |
| Peak TV will come back | ⚠️ **~36% below the 2021 peak and stabilized there** (§25.1) |
| TV got worse | ⚠️ **Ratings suggest volume fell, not quality** (§25.1) |
| The guilds solved AI | ⚠️ **SAG-AFTRA got real terms; WGA got notification** (§25.2) |
