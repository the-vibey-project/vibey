## §29. Quick Reference

### 29.1 Picker
| Problem | Where |
|---|---|
| The story feels like a list of events | ⚠️ **"And then" vs "therefore/but"** (§2 → `story-rules-character-structure-and-scene`) |
| The scene is flat | ⚠️ **What does each person want IN THIS SCENE?** (§5 → `story-rules-character-structure-and-scene`) |
| The protagonist is boring | ⚠️ **They're passive. Give them agency** (§3 → `story-rules-character-structure-and-scene`) |
| The opening is slow | ⚠️ **Front-loaded exposition. Cut the first scenes** (§10 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| No tension | ⚠️ **Let the audience know something the characters don't** (§6 → `story-rules-character-structure-and-scene`) |
| Dialogue is on the nose | ⚠️ **Subtext — nobody says what they want** (§7 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| Everyone sounds the same | ⚠️ **Cover the names and test** (§7 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| The ending doesn't land | ⚠️ **Setup, and protagonist agency in the resolution** (§11 → `story-dialogue-point-of-view-theme-exposition-and-endings`) |
| The joke doesn't work | ⚠️ **Funny word last; check the misdirection is honest** (§13 → `story-comedy-jokes-improv-standup-and-timing`) |
| The comic scene is just weird | ⚠️ **Find the game. Random isn't funny** (§14 → `story-comedy-jokes-improv-standup-and-timing`) |
| The comedy feels mean or misfires | ⚠️ **Check the target and the distance** (§12 → `story-comedy-jokes-improv-standup-and-timing`, §19 → `story-comedy-jokes-improv-standup-and-timing`) |
| The performance is indicating | ⚠️ **Play an action, not an emotion** (§20 → `story-acting-directing-medium-and-industry`) |
| The cut feels wrong | ⚠️ **Comedy timing is frames. Try trims either side** (§18 → `story-comedy-jokes-improv-standup-and-timing`, §23 → `story-acting-directing-medium-and-industry`) |
| Low budget — where to spend? | ⚠️ **Sound** (§23 → `story-acting-directing-medium-and-industry`) |
| Got contradictory notes | ⚠️ **Find the shared problem, ignore the proposed fixes** (§24 → `story-acting-directing-medium-and-industry`) |

### 29.2 Scene diagnostic
- [ ] ⚠️ **Someone wants something SPECIFIC in this scene** (§5 → `story-rules-character-structure-and-scene`)
- [ ] ⚠️ **Something concrete is in the way** (§5 → `story-rules-character-structure-and-scene`)
- [ ] ⚠️ **The scene TURNS — it ends somewhere different** (§5 → `story-rules-character-structure-and-scene`)
- [ ] Entered as late as possible, left as early as possible (§5 → `story-rules-character-structure-and-scene`)
- [ ] ⚠️ **What's said ≠ what's wanted** (§7 → `story-dialogue-point-of-view-theme-exposition-and-endings`)
- [ ] The audience knows something useful the characters don't (§6 → `story-rules-character-structure-and-scene`)
- [ ] ⚠️ **Nothing here is explaining what the audience could infer** (§10 → `story-dialogue-point-of-view-theme-exposition-and-endings`)
- [ ] ⚠️ **Cut it and see if anything breaks** (§5 → `story-rules-character-structure-and-scene`)
