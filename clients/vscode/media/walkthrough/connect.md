# Connect to vibey on this network

Local is the default, and it needs no hub at all. When vibey runs on another computer
(`vibey serve`, on port 8765 by default), **krypton: Connect to vibey on this network** finds
it: first on this computer, then at a name you type, such as `studio.local`.

Being on the same network proves nothing, so you pair once. Paste the key the host gave you:
its token, or a device key. krypton checks it with the hub before keeping it, in the editor's
secret storage, never in settings.

**krypton: Disconnect from the hub** takes you back to local at once.
