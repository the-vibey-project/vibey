* **Every error has a permanent code, and `vibey explain` explains it:** guarded commands now end an error's output with a code line (`(E0040: run `vibey explain E0040`)`) after the unchanged `Error: <message>` first line and any next-step hint. `vibey explain CODE` prints the cause and what to do (no database needed), `vibey explain --list` prints them all, and an unknown code exits 2 naming the nearest. The codes live in one declared table, `src/vibey/cli/error_codes.toml`, with an entry for every concrete `VibeyError` subclass (73 today); `docs/reference/errors.md` is generated from it by `scripts/error_catalog.py`, and a test fails for an error type with no entry, an entry naming no class, a reused code, or a hint missing from its fix. Codes are never reused or renumbered. Commands outside `guard()`, `vibey state` and the hub's HTTP error bodies do not carry codes yet. #1691.
