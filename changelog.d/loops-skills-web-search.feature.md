`vibey loops --json` reports every capability a loop's descriptor holds: each engine's `capabilities` object gains `skills` and `web_search` (`true`, `false` or `null`), beside the existing keys, with their evidence where it is set. The human tables add one line per engine, `<engine> capabilities: yes ...; no ...; unknown ...`. The CLI reference's `capabilities` row and its per-loop table now match the descriptors (codexloop's MCP is unknown; gptossloop and qwenloop show MCP and web search), and a meta-test keeps the row naming every capability.
