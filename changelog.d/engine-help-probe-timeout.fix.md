The engine adapter's `run --help` probe now has a `help_timeout` (default 30 seconds) instead of a hard-coded 10. A probe that timed out reported no help text, so on a busy host every flag an engine descriptor names read as absent and the flags conformance check failed; it also made the scripted live-binary conformance test flaky under load. The live test widens it the way it already widens `version_timeout`.
