Marketplaces can be pinned by content. A marketplace's tree hashes to one `sha256:` digest that does not depend on the order the file system lists it in, counts a symlink by the text it points to without ever following it, leaves out only the clone's own `.git` at the top of the tree, recognised by what it is rather than how its name is spelled (on a case-insensitive file system `.GIT` is the same folder; on a case-sensitive one a separate `.GIT` is ordinary content and is hashed), hashes a `.git` deeper down like anything else, and refuses any plugin or skill that reaches a `.git` under any spelling, so nothing the digest skips can be loaded, and refuses a FIFO or device rather than opening it. The lock that records these digests is written atomically (a temporary file beside it, synced and renamed over it, mode 0600) and carries a checksum that catches corruption and hand edits (it is not a signature: anyone who can write the file can recompute it); a lock that is truncated, corrupted, oversized, a symlink or not a regular file is refused whole, never read in part, and a FIFO in its place is refused rather than waited on. Nothing writes or checks the lock during a run yet.
