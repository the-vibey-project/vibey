Marketplaces can be pinned by content. A marketplace's tree hashes to one `sha256:` digest that does not depend on the order the file system lists it in, counts a symlink by the text it points to without ever following it, leaves out only the clone's own `.git` at the top of the tree (a `.git` deeper down is hashed like anything else, and a plugin or skill that resolves into a `.git` is refused, so nothing the digest skips can be loaded), and refuses a FIFO or device rather than opening it. The lock that records these digests is written atomically (a temporary file beside it, synced and renamed over it, mode 0600) and carries a checksum; a lock that is truncated, edited by hand, oversized or a symlink is refused whole, never read in part. Nothing writes or checks the lock during a run yet.
