A loop capability bundle can be resolved into a run's own snapshot, used only as it was locked. Only the marketplaces the enabled plugins come from are read, each from a folder the conductor names (never the bundle's `source` and never a project's file): a person-added marketplace with no lock entry stops the run and names `vibey loops marketplace update <name>`, a marketplace whose files changed after it was locked, or whose lock pins another source, stops it the same way, and the marketplace that ships with vibey locks itself the first time it is used (and again only when a new release ships a new copy). The selected plugins are copied into a fresh folder only the person can read, as plain bytes with no hard links and no symlinks and within size and entry caps, and the copy is compared with what was locked before anything loads from it, so a file swapped in after the check is refused rather than read. Disabled plugins, skills and MCP servers are absent; skill descriptions are capped at 1024 characters and stripped of control and bidi characters; a skill name two plugins share goes to the first in bundle order. The snapshot carries a digest of the bundle and the lock entries it used, the same for the same inputs. Nothing calls the resolver during a run yet.
