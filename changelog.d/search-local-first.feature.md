Web search is local first. Every search vibey controls (`vibey search`, the DESIGN research stage, and the gptossloop and qwenloop `web_search` tool, which runs `vibey search`) asks a local SearXNG first: `VIBEY_SEARXNG_URL`, else `http://127.0.0.1:28180` (loopback, on vibey's own uncommon port), so search is always configured and `vibey worker` always tells sessions where it is. Nothing there is believed until it proves it is a SearXNG: a GET of its `/config` must answer SearXNG's JSON and, when `VIBEY_SEARXNG_INSTANCE` is set, that `instance_name`; something else on the port (HTML, other JSON, a redirect, another instance) counts as SearXNG being unavailable, and its results are never read. A proof is kept per process for `VIBEY_SEARCH_IDENTITY_TTL` seconds (default 60). Brave is only a backup: a query goes to Brave only when that SearXNG failed (unreachable, timed out, any HTTP error, not JSON, no results list, or every engine unresponsive) and a Brave key is set; an empty answer from a healthy SearXNG never does. The first Brave answer in a process is said once on standard error (`local SearXNG unavailable (<reason>); this query went to Brave Search`, never the query), and every answer names its backend (`backend` in `vibey search --json`, kept beside `provider`; a `backend:` line in its text output; the DESIGN evidence's source). With SearXNG down and no key, a search fails saying where it looked and how to fix it. Search backends now follow a redirect only to the same origin and reach a loopback SearXNG without a proxy. `vibey doctor` and `vibey acp`'s doctor step gain `web-search` (the local SearXNG answering, or a `WARN` with the fix, including when something other than SearXNG is listening) and `web-search-backup` (configured via which variable, never the key); existing lines and `--json` keys are unchanged. Engine sessions still never receive the Brave key, so a session's search is the local SearXNG alone. **Breaking:** `VIBEY_SEARCH_PROVIDER=brave` is refused (exit 2, and the worker will not start): unset it and keep the key, which is then used automatically when SearXNG is down. A Brave key alone no longer makes Brave the backend: install or start a local SearXNG (or point `VIBEY_SEARXNG_URL` at yours), or every search goes to Brave with the notice.
