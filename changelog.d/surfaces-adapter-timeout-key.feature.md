**`[surfaces] adapter_timeout_seconds` declares the bound on a surface adapter's network calls** (#726). An integer from 1 to 600, default 10, overridden by `VIBEY_SURFACES_ADAPTER_TIMEOUT_SECONDS` (doctrine 12.c: a declared key with an environment override and a stated default, never only a constant). Out-of-range and non-integer values are refused by name. The adapters' built-in `timeout` default, `DEFAULT_SURFACE_ADAPTER_TIMEOUT_SECONDS`, is now 10 seconds (it was 30 in the first adapter fix), so the key's default and the adapters' agree; nothing yet passes the configured value to the adapters.
