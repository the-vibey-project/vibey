The JSON-RPC codec, error vocabulary and peer that vibey's MCP server and ACP agent use now live in `vibey-runners-common` (`vibey_runners.common.jsonrpc`), with an MCP client beside them (`vibey_runners.common.mcp`: persistent sessions, a per-run pool, a stdio transport and a streamable HTTP transport) that the local runner uses (SP-LOOPS Phase 5, R1 and R2). `vibey.infrastructure.jsonrpc` and `vibey.domain.jsonrpc_errors` are gone, with no re-export; nothing vibey's MCP server or ACP agent writes changes, and a meta-test holds vibey to one JSON-RPC peer. The protocol versions vibey's MCP server answers (`SUPPORTED_PROTOCOLS`, `LATEST_PROTOCOL`) move into the same package, so the client and the server read one list.
