**The documented first hour is now timed every week, with a named owner and a quarterly survey** (#1692). `scripts/first_hour.py` performs CONTRIBUTING.md "Your first hour" (clone, `vibey-gh setup`, the first test, the chaos test against PostgreSQL) in an empty directory on a GitHub-hosted runner, times each step, and appends one line to `docs/architecture/evidence/first-hour.jsonl`; the guide's generated block states the latest complete run, what the runner stood in for, and the owner. A run that fails part-way is recorded with its failing step and never becomes the stated time. In the months `scripts/first_hour.toml` declares, one survey issue opens and every answer is folded into `docs/architecture/evidence/first-hour-survey.jsonl` by comment id, so a late or out-of-order answer is read once and none is skipped. The first measurement lands when the `First hour` workflow first runs; until then the guide says "Not yet measured".
