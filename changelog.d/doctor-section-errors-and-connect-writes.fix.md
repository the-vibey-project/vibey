`vibey doctor`: a local section that raises no longer stops the doctor with a traceback. It prints `FAIL <section> <ExceptionType>: <first line of the message>` (credentials in a URL replaced by `***`), the other sections still run, and the exit code is 1. `vibey connect` now writes each client's config atomically (a temporary file renamed over it), keeps the file's permissions (a new one is owner-only), gives the `.vibey.bak` backup the original's permissions instead of the umask's, never follows a symlinked backup path, and refuses a config under your home folder whose real path is outside it.
