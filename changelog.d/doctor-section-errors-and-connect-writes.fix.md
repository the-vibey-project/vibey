`vibey doctor`: a local section that raises no longer stops the doctor with a traceback. It prints `FAIL <section> <ExceptionType>: <first line of the message>` (credentials in a URL replaced by `***`), the other sections still run, and the exit code is 1. `vibey connect` now writes each client's config atomically (a temporary file renamed over it), keeps the file's permissions (a new one is owner-only), gives the `.vibey.bak` backup the original's permissions instead of the umask's, and writes each config only inside its scope's root: a user-level config only where its folder resolves (symlinks followed) inside your home folder, a project config (`.mcp.json`, `.vscode/mcp.json`) only inside the project folder. A config or backup file that is itself a symbolic link is refused, and the files are opened relative to the resolved folder with `O_NOFOLLOW`, so a link swapped in after the check is never followed.
