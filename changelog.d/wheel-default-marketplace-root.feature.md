The installed package now carries the marketplace that ships with vibey as a marketplace folder, `vibey_skills/marketplace/` (`.claude-plugin/marketplace.json` beside `plugins/`, and nothing else), so a fresh install can read and lock the research skills with no network. The plugins tree moved there rather than being copied, so the wheel is no larger; `vibey_skills.marketplace_root()` names the folder, `vibey-skills marketplace` now prints that folder (the form `/plugin marketplace add <folder>` takes, rather than the manifest file), and `vibey-skills path` prints its `plugins/`.
