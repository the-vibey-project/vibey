* **`--json` for `vibey engines`, `vibey cost` and `vibey ledger show`:** each prints one document on stdout, with a message such as there being no project on stderr and every exit code unchanged. `engines --json` is `{"project_id", "engines": [...]}` with the nine keys `status --json` already carried under `circuits` (that code now writes both, so they cannot disagree). `cost --json` is `vibey budget show --json`'s project id, name, cycle, caps, spend and `exhausted`, plus each engine's BUILD spend across all cycles as `cost_usd_all_cycles` (the database column is called `cost_usd_cycle` but accumulates across cycles). `ledger show --json` is every field of every event, in `ledger search --json`'s shape. The text output is byte-identical, `vibey --help`'s footer now names every command that takes `--json`, and `engines` and `cost` moved out of `main.py` into classes with interfaces. `engines` and `cost` now run under `guard()`, so an unset `VIBEY_PG_URL` is a sentence with its error code and exit 3 instead of a traceback; `--traceback` on those two commands keeps the raw Python error reachable. `vibey doctor --json` is not part of this change. Part of #1686.
