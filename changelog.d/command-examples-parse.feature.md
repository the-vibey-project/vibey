**Every documented command example is now proved to run as written** (#1616, doctrine 3). A `@vibey/core` test feeds each `example` in the one command table through the slash parser and requires it to resolve to the command it documents, so a typo in an example, or a renamed slash word, fails the build instead of leaving the README and the table agreeing with each other while both are wrong. It proves syntax only: it cannot show that an id or path inside an example exists.
