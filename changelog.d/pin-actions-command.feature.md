**`vibey-gh pin-actions` pins every GitHub Action to a commit SHA** (`vibey-gh pin-actions [--apply] [PATH ...]`; SP1-C Task 1 of the optimization program). Without `--apply` it reads the workflows and composite actions, makes no network call, names every `uses:` that is not a 40-hex commit and exits 1. With `--apply` it resolves each distinct `(action, ref)` once through the commits endpoint, which gives the commit an annotated tag points at rather than the tag object, and rewrites the line to `uses: owner/repo@<sha> # <ref>`. It reads the file line by line instead of round-tripping the YAML, so nothing else in a workflow is reformatted, and it leaves alone `uses:` text inside a `run:` script or a comment, local `./` actions and `docker://` references. A use it cannot rewrite is listed as `path:line` and the run exits 1, so it never reports a pin it did not make. This change adds the tool only; applying it to the repository is the next change.
