**Minor release 0.4.0 of every component** (`vibey-engine`, `krypton-app`, `claudeloop`, `codexloop`, `qwenloop`, `vibey-runners-common`, `vibey-gh`, `vibey-bootstrap`, `vibey-skills`, the krypton mobile and web app, the desktop client, `@vibey/core` and the VS Code extension). It is 0.4.0 and not the staged 0.3.1 because the version rule (`[version] content_paths`) makes any change to packaged source a minor, so `vibey-gh promote` had already raised the staged 0.3.1 to 0.4.0; the bump is now staged deliberately at 0.4.0. Open VSX refused to republish the extension's removed 0.3.0, so the extension ships as 0.4.0. The engine adapter's `run --help` probe timeout is now configurable (`help_timeout`, default 30 s; #1907). Staged only: the managed workflows stay pinned to `vibey-engine==0.3.0` (`[install] pin = "0.3.0"`) until 0.4.0 is published.
