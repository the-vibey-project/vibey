**Every versioned component now sits at 0.3.0, pre-1.0** (`claudeloop`, `codexloop`, `vibey-runners-common`, `vibey-gh`, `vibey-bootstrap`, `vibey-skills`, the krypton mobile and web app, the desktop client and `@vibey/core`; `vibey-engine`, `krypton-app`, `qwenloop` and the VS Code extension were already there).
