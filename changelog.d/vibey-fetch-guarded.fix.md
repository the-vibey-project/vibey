`vibey fetch` -- and so the `web_fetch` tool of gptossloop and qwenloop, which runs it, and the DESIGN research's page reads -- now goes through the hub's guarded fetch (`GuardedPageFetch`, with the same policy as `vibey_fetch`), so it is never weaker than what the hub serves an agent: decimal, octal and hex IPv4 spellings, IPv6, IPv4-mapped and NAT64 forms, local, internal and metadata names are refused before any connection; every address a name resolves to must be public and the one checked is the one connected to; no redirect goes from https down to http; a compressed answer is refused before its body is read; and a fetch is bounded by one deadline in all. `[web]` (your own `vibey.toml`, narrowed by the current folder's) now applies: `allow_hosts`, `deny_hosts`, `content_types`, `max_bytes`, `max_chars`, `max_redirects` and `timeout_seconds`; `--max-chars` may lower `[web] max_chars`, never raise it. The `--json` output keeps its fields (`untrusted`, `url`, `title`, `truncated`, `text`); refusal messages now use the hub's wording (for example `refused: not a public host name ...` instead of `refused: not a public http(s) address`).
