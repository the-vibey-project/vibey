`vibey acp` is an Agent Client Protocol agent an editor such as Zed launches over stdio, and `vibey connect` now registers it with Zed: `--client zed` (and a plain `vibey connect`) writes `agent_servers.vibey = {"type": "custom", "command": "<this install's vibey>", "args": ["acp"], "env": {}}` into `~/.config/zed/settings.json` on macOS and Linux, keeping every other setting and agent server, with the same atomic, no-wider, never-through-a-link write and `.vibey.bak` backup as every other client; `vibey acp`'s own connect step does the same when `~/.config/zed` exists. Zed keeps comments in its settings, and vibey never rewrites a file it cannot read as strict JSON: such a file is left as it is and refused with the exact snippet to paste, unless it already carries that entry (then it is left alone as connected); the other clients still connect and `vibey connect` exits 1. A refused client no longer stops the whole plan (it exited 2 before). Every entry `vibey connect` writes now runs the running install's own `vibey` (the console script beside its Python), never one found on `PATH`, as `vibey acp`'s connect step already did; `--list` and the plan show each client's protocol (`mcp` or `acp`). `vibey connect`, `vibey doctor` (a new `llm-tooling` section, last) and `vibey acp`'s doctor step now report, per detected client, each LLM-facing surface vibey offers it -- the ACP agent entry, the MCP server entry, the `vibey-chat-driver` skill (Claude Code through the `vibey` plugin or `~/.claude/skills`, Codex in `~/.codex/skills`) and the `vibey` plugin from the root marketplace (Claude Code) -- as present (`PASS`), missing (`WARN`, with the exact command or snippet that fixes it) or not applicable (`UNKNOWN`); the section only reads, never through a symbolic link, never a non-regular file or more than 1 MiB, and never fails doctor. `vibey doctor --json` reports these as `checks` named `<client>:<surface>`, with no new key. The editor launches `vibey acp`; on first contact it runs doctor and connect, loads the user-level hub and worker units and keeps them running (ADR-0101); see the new ACP guide.
