A marketplace's own `.git` folder is now recognised by what it is, not only by how its name is spelled. On a case-insensitive file system (macOS by default) `.GIT` or `.Git` is the same folder as `.git`, so a plugin or skill that reaches it under another spelling is refused just like `.git` itself, and the lock's digest leaves out exactly that same folder: on a case-sensitive file system a separate `.GIT` folder is ordinary content and is hashed.
