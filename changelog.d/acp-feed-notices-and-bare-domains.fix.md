`vibey acp`: a bare host in hub or ledger text (`evil.com`, `docs.evil.co.uk/x`, `evil.xn--p1ai`, `README.md`) is now defanged like a full URL, every dot bracketed (`evil[.]com`), whenever its last label has a top-level domain's shape (two or more characters from a letter of any script, or punycode `xn--`), Unicode full stops a browser reads as dots (`evil。com`) included, so a client that links bare domains cannot make one clickable; the only names left as written are two-label ones ending in a suffix of vibey's own files that is no top-level domain (`vibey.toml`, never `evil.com.toml`). The live feed's "Live updates paused", "resumed" and "stopped" are now `notice` updates (warning, info, error) for a client that declares `session.notices`, and messages otherwise. A project the hub no longer has (a 404) now stops the feed with one "Live updates stopped: the hub has no project <id> any more" instead of being retried for ever. On macOS, on a volume that folds case (asked of the volume itself, so a case-sensitive APFS volume is not folded), a session's folder now finds its project in another case (`/Work/App` is `/work/app`), the deepest repository still winning and an exact match breaking a tie, and a folder lookup that lands while a prompt is being sent no longer changes the project the hub reads that prompt with. Unit labels in vibey's own notices (keep-alive, the first load, the SearXNG step) are shown exactly, in a code span, so a label copied from one names its unit.
