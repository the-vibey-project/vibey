`vibey acp`: a bare host in hub or ledger text (`evil.com`, `docs.evil.co.uk/x`, `evil.xn--p1ai`, `README.md`) is now defanged like a full URL, every dot bracketed (`evil[.]com`), whenever its last label has a top-level domain's shape (two or more characters from a letter of any script, or punycode `xn--`), so a client that links bare domains cannot make one clickable; the only names left as written end in a suffix of vibey's own files and units that is no top-level domain (`vibey.toml`, `dev.vibey.hub`). The live feed's "Live updates paused", "resumed" and "stopped" are now `notice` updates (warning, info, error) for a client that declares `session.notices`, and messages otherwise. A project the hub no longer has (a 404) now stops the feed with one "Live updates stopped: the hub has no project <id> any more" instead of being retried for ever. On macOS a session's folder now finds its project whatever the case (`/Work/App` is `/work/app`), and a folder lookup that lands while a prompt is being sent no longer changes the project the hub reads that prompt with.
