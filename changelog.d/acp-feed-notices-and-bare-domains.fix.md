`vibey acp`: a bare host in hub or ledger text (`evil.com`, `docs.evil.co.uk/x`, `README.md`) is now defanged like a full URL, every dot bracketed (`evil[.]com`), whenever its last label is a top-level domain a client links on its own (any two letters, the common generic ones, or a non-ASCII one), so a client that links bare domains cannot make one clickable; vibey's own names under no such domain (`dev.vibey.hub`, `vibey.toml`) are left as they are. The live feed's "Live updates paused", "resumed" and "stopped" are now `notice` updates (warning, info, error) for a client that declares `session.notices`, and messages otherwise. A project the hub no longer has (a 404) now stops the feed with one "Live updates stopped: the hub has no project <id> any more" instead of being retried for ever. On macOS a session's folder now finds its project whatever the case (`/Work/App` is `/work/app`), and a folder lookup that lands while a prompt is being sent no longer changes the project the hub reads that prompt with.
