**The Plane, BookStack, OpenBao and Infisical adapters bound every HTTP call** (#727). Each took its opener with no timeout, so a server that accepted the connection and never answered blocked the calling thread for ever. Each adapter now takes a keyword-only `timeout` (default `DEFAULT_SURFACE_ADAPTER_TIMEOUT_SECONDS`, 30 seconds, in `vibey.domain.config`) and passes it on every request; a call that exceeds it raises what `urlopen` raises. Nothing else about the adapters changed.
