**The README has a table of contents** (#853). A `## Contents` list after the first screen links to each of the README's other sections, so a reader on GitHub or on PyPI's page, which has no outline of its own, can jump to Install, Quickstart, Configuration and the rest without scrolling. A new meta test, `tests/meta/test_readme_contents.py`, keeps it true: one entry per `##` heading in order, each pointing at that heading's own anchor, so adding or renaming a section without updating the list fails the build instead of leaving a dead link. The list sits after the first screen, so `tests/meta/test_first_screen.py` still holds the first screen to the same contract.
