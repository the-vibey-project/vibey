The pure half of Agent Client Protocol support (SP-ACP): ACP v1 method names, enums and error codes, a new `[acp]` table in `vibey.toml` (read by name, an unknown key or an out-of-bound value refused by name), the `observe` and `drive` session modes with the hub scopes each may use (never `spend`), and a per-session state machine that gives every prompt turn exactly one stop reason and resolves every pending permission when a turn is cancelled. The official `agent-client-protocol` SDK joins the dev dependencies only, to check these shapes in tests.
