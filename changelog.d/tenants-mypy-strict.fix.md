* **tools:** `vibey_gh`, `vibey-skills` and `vibey_bootstrap` now pass `mypy --strict` and CI holds each to it (the `tools` matrix gives `vibey-skills` a `static` row, and a meta test fails if a tenant is not strict or not checked). `SovereignRunner` now accepts `RunnerPlanInterface` and `LaunchAgentUnitInterface` instead of the concrete classes, which is what `SovereignRunnerInterface` declares. The egress gate template lost two now-unused `type: ignore` comments, so a runner that is already installed will report `drift` from `vibey-gh runner check` until `vibey-gh runner install` is run again.
