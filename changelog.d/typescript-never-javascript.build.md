* **javascript:** every JavaScript file is now TypeScript (sub-doctrine 9.f, ADR-0088). The site scripts
  (`channel`, `math`), the VS Code panel, the VS Code build and smoke scripts and the krypton app's Babel
  and Metro configuration are written in `.ts`; the `.js` a browser or Expo must load is generated by
  `scripts/typescript_artifacts.py` and checked for drift in CI. The cookie-consent banner and analytics
  start-up that the release workflow wrote as JavaScript strings are now `analytics.ts` and `consent.ts`,
  inlined from compiled assets and configured by `data-` attributes.
