Web search accepts the Brave Search key under `BRAVE_SEARCH_API_KEY`, the name Brave's own tools read, as an alias of `VIBEY_BRAVE_API_KEY`; `VIBEY_BRAVE_API_KEY` wins when both are set, and Brave is still chosen only when SearXNG is not configured (or `VIBEY_SEARCH_PROVIDER = brave`). The key stays in vibey's own processes: the alias joins the rule under every child's environment allow-list, so no engine session or gate can be given it even by a declared name or prefix, and it is never in a `repr`, an error or a log line. The worker's web-search line now says which variable configured Brave (`configured via BRAVE_SEARCH_API_KEY`), never the key, and the not-configured hints name the alias.
