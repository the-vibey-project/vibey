**BREAKING: `vibey -v` is now the version flag, and verbose moves to `--verbose` or `-d`** (`vibey` CLI). `vibey --version` and `vibey -v` print two lines, `vibey-engine <version>` then `krypton-app <version>` (`krypton-app not installed` when the app is absent), and exit 0 before any subcommand is parsed, so `vibey -v status` prints the versions and does not run `status`. The counted verbose flag keeps `--verbose` and gains the short form `-d`: `-d` debug, `-dd` also third-party libraries, `-ddd` full payloads and the LLM wire log. Anything that ran `vibey -v`, `-vv` or `-vvv` to get logging must now run `vibey -d`, `-dd` or `-ddd`. The `claudeloop`, `codexloop` and `qwenloop` commands keep their own `-v`.
