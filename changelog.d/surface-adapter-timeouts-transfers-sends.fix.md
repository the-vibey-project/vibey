**The Nextcloud, Garage, RabbitMQ, Matrix, Wazuh and Kannel adapters bound every HTTP call** (#728, #729). Like the four adapters before them, each took its opener with no timeout, so a server that accepted the connection and never answered blocked the calling thread for ever, and a hung SIEM sink did exactly what its port promises never to do. Each adapter now takes a keyword-only `timeout` (default `DEFAULT_SURFACE_ADAPTER_TIMEOUT_SECONDS`) and passes it on every request. The RabbitMQ bound lives in `RabbitMqManagementApi`, so the queue inspector's own calls are bounded too. A call that exceeds it raises what `urlopen` raises.
