`vibey acp`: a session now follows a project's ledger. The project is the one whose repository holds the session's folder (the deepest when repositories nest), or the one the hub's last reply named, which wins; it is also what a prompt's commands default to. The editor shows the project's phase plan (Design, Visual design once seen, Build, Review and the three deploy phases), re-sent when the phase changes, and each new ledger event as one plain-text message, `[<phase>] <kind>: <summary>`, cut to `[acp] live_message_chars`. Each live message is its own paragraph, and ledger text (and any other hub data shown, such as a project's name) is escaped for Markdown, so it can make no link, image, heading or code block; the hub chat's own reply is passed through as Markdown. When the folder chooses the project you are told which one, since bare `/start`, `/pause` and `/abandon` now target it. History is not replayed. The feed polls from a ledger position (sub-doctrine 10.g), so a hub restart neither skips nor repeats an event; a failed read is reported once and retried after `[acp] live_poll_seconds`, the wait doubling up to `[acp] probe_seconds`. With `[acp] live_between_turns = false`, events between turns are held (at most `pending_events_max`) and sent when the next prompt starts. A gate's event is only ever a message and can never mark, answer or hide a gate; one that says its gate spends money adds a notice to answer it on the host. Right after `session/new` the editor gets every `/` command with its usage as the input hint, and `session/set_mode` switches between the offered modes with a `current_mode_update`. A switch to observe applies at once: a permission request still out is withdrawn, an answer picked after the switch answers nothing, the turn's remaining gates are not offered, and a command not yet sent to the hub is not sent. A gate held back in observe is offered after a switch to drive. A defect in reaching the hub is no longer reported as the hub being unreachable: only a connection failure is, and any other error keeps its own name and is logged with its traceback.
