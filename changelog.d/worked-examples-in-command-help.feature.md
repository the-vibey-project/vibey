* **Worked examples at the end of six commands' `--help`:** `new`, `answer`, `gates`, `projects`, `doctor` and `watch` now end `--help` with one or two runnable examples, kept in one table (`vibey.cli.command_examples`) and checked by a test that resolves each line against the real command tree with the command's own parser, so a renamed flag or removed command fails a test instead of rotting. `vibey new` now describes `NAME` (a label, not required to be unique) and `vibey answer` describes `GATE_ID` and the `QUESTION_ID=ANSWER` pairs, in place of the bare `{name}` and `{gate_id}`. Rarely used options are grouped under named panels (`new`: Spending and turn limits, Skills, Advanced; `doctor`: Recording, In-cluster preflight, Capacity probe; `answer`: Advanced; `gates`: Reminders), and the shared `--ignore-sabbath` option sits under Advanced in `new`, `work` and `worker`. No option was renamed, removed or given a new default. #1687.
