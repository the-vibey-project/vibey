**Every table in the configuration reference has a copy-pasteable `vibey.toml` snippet** (#847). The 25 `## \`[table]\`` sections of `docs/reference/configuration.md` that had none (`[project]` through `[siem]`, including `[failover]`, `[supervisor]` and `[hub]`) now carry a fenced `toml` block right under their field table, using only keys that table documents. The snippets are checked to be valid TOML and, for the tables `parse_config` reads, to load. Secrets are `REPLACE_ME` placeholders. Only lines were inserted.
