`scripts/install.sh --full` runs vibey's own setup after the install, in order, and stops at the first step that fails, naming it and the command that re-runs it: `vibey install --postgres`, `vibey migrate` when `VIBEY_PG_MIGRATE_URL` is set, and `vibey connect --yes`. Each step can be skipped (`VIBEY_FULL_POSTGRES=0`, `VIBEY_FULL_MIGRATE=0`, `VIBEY_FULL_CONNECT=0`) and `VIBEY_FULL_CONNECT_CLIENTS` narrows the clients. It says before a step that sudo may ask for a password, and stops when there is no terminal to ask on. Creating the database and pulling the Ollama model have no vibey command yet, so `--full` prints what to run for them. The installer also now finds `vibey` in uv's tool directory when it is not on `PATH` (and fails with the line to add when it is not there either), prints `--help` when piped, and names an uninstall command that exists after a piped install, only when krypton was installed.
