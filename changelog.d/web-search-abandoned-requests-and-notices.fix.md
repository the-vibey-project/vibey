Web search: a request to SearXNG or Brave abandoned at its total deadline now has its connection shut down, so its thread ends at once instead of living as long as a listener that trickles its answer likes. The sovereign runner's `web_search` tool now passes on only vibey's own backup notice from `vibey search`'s standard error (one clean line each, at most 500 characters), never other error output, terminal escapes or tracebacks.
